## 1. 앱 한 줄 소개

**차차, 우리(Bye & By, Us)** — 반복되는 알림에 무뎌진 운전자에게 꼭 필요한 순간 가족의 목소리로 주의를 일깨우고, 운전하는 내내 가족과 함께하는 안전과 따뜻함을 선사하는 차량 앱입니다.

---

## 2. 기획 배경

### 주목한 문제 — 알림이 많을수록 중요한 알림을 놓칩니다
고속도로를 달리면 내비는 구간단속, 제한속도, 과속 카메라, 차로 안내를 쉬지 않고 알려 줍니다. 모든 안내가 **같은 목소리, 같은 무게**로 나옵니다.

운전에 익숙한 사람일수록 이 반복에 길들여집니다. 매일 같은 길을 오가는 운전자는 안내를 배경 소음처럼 흘려듣고, 그 사이에 섞여 나오는 "1km 앞 출구입니다" 같은 **정말 중요한 안내까지 함께 놓칩니다.** 결국 출구 직전에 급하게 차선을 바꾸거나, 분기점에서 갑자기 방향을 틀게 됩니다.

오래 달릴 때도 마찬가지입니다. 단조로운 고속도로를 계속 달리면 의식이 멍해지는 상태가 이어지고, 이때 나오는 휴식 안내도 "휴게소네" 하고 지나칩니다. 졸린지 스스로 돌아보지도 못한 채 운전을 계속합니다.

### 나만 느끼는 문제가 아닙니다
- **경보 피로·습관화**: 같은 경고가 반복되면 사람은 그 경고에 무뎌져 반응하지 않게 됩니다 `[근거: 경보 피로(alarm fatigue), 습관화 연구]`
- **고속도로 최면**: 단조로운 고속도로를 오래 달리면 깨어 있어도 주변 자극에 둔해지는 상태가 됩니다 `[근거: 고속도로 최면(highway hypnosis) 자료]`
- **진출입부·분기점 사고**: 고속도로 진출입부와 분기점에서는 급차로 변경 사고가 잦습니다 `[근거: A8]`
- **졸음·주시 태만**: 고속도로 사망 사고에서 졸음과 주시 태만 비중이 높습니다 `[근거: A4]`

### 기존 방법으로는 풀리지 않는 이유
| 기존 방법 | 한계 |
|---|---|
| 내비 안내 | 중요도와 상관없이 모든 안내가 같은 목소리라, 익숙해지면 함께 흘려듣습니다 |
| 차량 경고음 | 처음엔 놀라지만, 반복되면 무시하게 됩니다 |
| 휴식 안내 | 다른 안내와 똑같이 들려서, 멍한 상태에서는 귀에 들어오지 않습니다 |
| 안내를 더 늘리기 | 알림이 늘수록 피로가 쌓여 오히려 더 무뎌집니다 |

**필요한 건 알림을 늘리는 게 아니라, 꼭 들어야 할 알림만 다르게 들리게 하는 것입니다.**

### 왜 가족의 목소리인가
익숙한 내비 음성은 흘려듣지만, 가족의 목소리는 그냥 지나치지 못합니다. 많은 소리 속에서도 자기 이름이나 아는 사람 목소리는 저절로 귀에 들어옵니다 `[근거: 친숙한 목소리·자기 이름에 대한 주의 연구]`. 그리고 가족의 목소리는 경고음처럼 놀라게 하지 않으면서도 정신을 깨웁니다.

## 3. 앱 주요 기능 및 차량 특화 요소

### 핵심 — 꼭 들어야 할 순간만, 가족의 목소리로
| 기능 | 설명 | 차량 특화 |
|---|---|---|
| 중요한 길목만 고르기 | 경로 전체에서 **고속도로 출구·진입·분기점**만 고릅니다. 일반 교차로, 톨게이트, 터널은 내비에 맡깁니다 | 경로 길목 정보 |
| 미리, 한 번의 안내로 | 차선을 여유 있게 옮길 수 있을 때(남은 거리 ÷ 속도) 알립니다. 차 안내 "2km 앞 판교 IC 출구예요." 바로 뒤에 가족 목소리 "아빠, 이번에 오른쪽으로 나가야 돼"가 이어져 **한 번의 안내**로 들립니다. 안내 횟수는 늘지 않습니다 | 길목 거리, 차량 속도 |
| 반응하면 바로 멈춤 | 출구 쪽 깜빡이를 켜거나 핸들을 돌리면 그 길목 안내는 끝납니다. 이미 아는 운전자를 귀찮게 하지 않습니다 | 깜빡이, 조향각 |
| 한 번 더, 그래도 놓치면 괜찮아 | 반응이 없으면 한 번 더 차분하게 알립니다. 너무 가까워지면 무리한 끼어들기를 막기 위해 "괜찮아, 다음에서 나가면 돼" | 길목 거리, 속도 |
| 휴식 권유 | 쉬지 않고 오래 달리면 다음 졸음쉼터·휴게소 앞에서 "아빠, 오래 달렸네. 쉬었다 가자". 흘려듣던 휴식 안내를 가족 목소리로 깨웁니다 | 연속 주행 시간, 경로의 쉼터 정보 |
| 안전 알림이 먼저 | 길목 안내 직전이나 도중에는 다른 알림(가족 메시지 등)을 미뤘다가 지난 뒤 전합니다 | 길목 거리 |
| 멘트 네 개만 녹음 | 가족이 휴대폰 앱에서 오른쪽, 왼쪽, 놓쳤을 때, 휴식 네 가지만 녹음합니다. 장소 이름과 거리는 차가 말하므로 한 번 녹음하면 계속 씁니다. 녹음하지 않은 멘트는 기본 음성으로 채웁니다 | — |

### 부가 — 가족이 곁에 있다는 느낌
안전 알림을 위해 연결한 가족을, 평소에도 차 안에서 만날 수 있게 합니다.
- **가족 메시지**: 가족이 보낸 음성·글을 운전 중엔 소리로 바로, 아니면 시동을 켤 때 들려줍니다. 장소가 붙어 있으면 "목적지로 할까요?" → "응" 한마디로 내비 목적지가 바뀌고, 답이 필요하면 "전화해 줘"로 통화합니다
- **위치 공유**: 집으로 출발할 때 차가 묻고, 도착하면 자동으로 끝납니다. 가족 앱에는 위치를 요청하는 기능이 없습니다
- **인사 영상**: 시동을 켤 때와 집에 도착했을 때(정차 중)만 재생하고, 기어 D로 바꾸면 바로 멈춥니다

### 왜 차에서만 가능한가
- 경로의 출구·분기점, 차량 속도, 깜빡이·조향을 **함께** 보는 건 차량 앱만 할 수 있습니다 → 중요한 순간을 고르고, 운전자가 반응하면 멈춥니다
- 연속 주행 시간과 경로의 다음 쉼터를 알아야 쉼터 바로 앞에서 휴식을 권할 수 있습니다
- 휴대폰은 지금 운전 중인지 모릅니다. 차는 알기 때문에 주행 중엔 화면 없이 소리로만 전합니다

### 새로운 경험
내비는 모든 정보를 같은 목소리로 알려 줍니다. 차차, 우리는 그중 **꼭 들어야 할 순간만 골라 가족의 목소리로** 들려줍니다. 알림을 늘리지 않고 다르게 만듭니다. 운전자는 익숙한 길에서도 중요한 순간을 놓치지 않고, 오가는 길에 가족이 옆자리에 탄 듯한 느낌을 받습니다.

## 4. 주요 사용 시나리오

**등장인물**: 아빠(52세, 운전 경력 25년, 고속도로로 편도 한 시간 출퇴근), 딸 지은(22세), 아내(50세)
※ 호칭은 예시이며, 운전하는 가족 누구에게나 해당합니다.

**준비**: 지은이 휴대폰 앱에서 멘트 네 개를 녹음해 둡니다. "아빠, 이번에 오른쪽으로 나가야 돼", "아빠, 이번에 왼쪽으로 가야 돼", 아내가 "괜찮아, 다음에서 나가면 돼", 지은이 "아빠, 오래 달렸네. 쉬었다 가자".

| # | 상황 | 흐름 |
|---|---|---|
| 1 | 퇴근, 출발 | 내비에 집을 찍고 출발합니다. 매일 다니는 길이라 아빠는 안내에 크게 신경 쓰지 않습니다 |
| 2 | 고속도로, 쏟아지는 안내 | "구간단속 구간입니다", "제한속도 100", "전방 과속 카메라"… 아빠는 습관처럼 흘려듣습니다. 차차, 우리는 이 안내들에 끼어들지 않습니다 |
| 3 | 분기점 | 분기점 약 90초 전, 차 "2km 앞 OO분기점이에요." 바로 이어서 지은 목소리 "아빠, 이번에 왼쪽으로 가야 돼". 아빠가 왼쪽 깜빡이를 켜자 안내가 바로 끝납니다 |
| 4 | 출구, 반응이 없을 때 | 판교 IC 출구 안내 뒤에도 차선 변화가 없자, 약 40초 전에 한 번 더 차분하게 "아빠, 이번에 오른쪽으로 나가야 돼". 아빠가 여유 있게 차선을 옮깁니다 |
| 5 | 출구를 놓쳤을 때 (다른 날) | 출구가 너무 가까워지도록 반응이 없으면 더 재촉하지 않고 아내 목소리로 "괜찮아, 다음에서 나가면 돼". 급하게 끼어들지 않고, 내비가 다시 길을 찾습니다 |
| 6 | 휴식 권유 (주말 장거리) | 두 시간 가까이 쉬지 않고 달려 멍해질 무렵, 다음 졸음쉼터가 다가오자 "아빠, 오래 달렸네. 다음 쉼터에서 쉬었다 가자". 늘 흘려듣던 휴식 안내와 달리, 아빠는 쉼터로 들어갑니다 |
| + | 부가 — 퇴근길 가족 메시지 | 고속도로를 빠져나온 뒤, 출발 알림을 본 지은이 OO치킨을 붙여 "아빠 오늘 치킨 먹자~"를 보냅니다 → "OO치킨을 목적지로 할까요?" → "응". 출구 안내 중에 온 메시지였다면 출구를 지난 뒤에 전합니다 |

**달라지는 점**: 아빠가 들은 가족 목소리는 하루에 몇 번뿐이지만, 그때마다 꼭 핸들을 움직여야 하는 순간이었습니다. 안내는 늘지 않았고, 중요한 순간은 놓치지 않았습니다.

## 5. 개발 계획

### 구성
```
[가족 앱 (Android, Kotlin)] ─ 멘트 녹음 · (부가) 메시지·장소·인사 영상 ─▶ [Firebase]
        ▲                                                   Auth / Firestore / Storage
        │ (부가) 출발·목적지 변경·도착 알림                     Cloud Functions(녹음 보정)
        │                                                   ▼
        └──────────────────────────────── [차량 앱 (Pleos Connect, Kotlin)]
                                           포그라운드 서비스: 길목 안내, 휴식 권유, (부가) 메시지 전달
                                           정차 화면: 설정, 멘트 듣기, (부가) 메시지함·인사 영상
```

### 주요 개발 범위
| 구분 | 범위 |
|---|---|
| 차량 앱 — 핵심 | 길목 고르기(출구·진입·분기점), 남은 시간 계산과 두 단계 알림, 차 안내 + 가족 목소리 이어 붙이기, 깜빡이·조향으로 멈추기, 놓쳤을 때 안내, 연속 주행 시간 기반 휴식 권유, 안전 알림 중 다른 알림 미루기 |
| 차량 앱 — 부가 | 가족 메시지 전달(운전 중 / 시동 때), 목적지 변경 묻기와 실행, 전화하기, 위치 공유 시작·종료, 인사 영상 |
| 가족 앱 | 가족 묶기(차량 화면 QR·초대 코드), **멘트 네 개 녹음과 다시 듣기**, (부가) 메시지·장소 보내기, 위치 보기, 인사 영상 올리기 |
| 서버 | 계정·가족 그룹, 녹음 자동 보정(음량 평준화, 잡음 제거, 앞뒤 무음 자르기, 찢어짐 감지 시 다시 녹음 안내), (부가) 메시지 전달 |

### Pleos SDK·API 사용 계획 (✅ 에뮬레이터 실측 완료)
| 용도 | SDK / API | 실측 |
|---|---|---|
| 경로의 출구·진입·분기점·쉼터와 남은 거리 | NaviHelper `onTBTInfo` (`TURN_EXIT_IC_*`, `TURN_ENTER_IC_*`, `TURN_DEVIDE_MERGE`, `TURN_KEEP_L/R`) | ✅ |
| 남은 시간 계산, 연속 주행 시간 | AAOS `PERF_VEHICLE_SPEED`, `GEAR_SELECTION` | ✅ |
| 운전자 반응 → 안내 멈춤 | Vehicle SDK `TurnSignal`, `SteeringWheel` | ✅ |
| 출구 이름·거리 안내 (가족 목소리 앞부분) | Pleos TextToSpeech (`ON_DEVICE`) | ✅ |
| 가족 목소리 재생, 내비 안내와 겹치지 않게 | Android 오디오 포커스 | ✅ |
| 경로 시작·재탐색·도착 → 안내 초기화 | NaviHelper `onRouteStarted`, `onRouteCancelled`, `onDestinationArrived` | ✅ |
| 주행 중 화면 제한 | AAOS `CarUxRestrictions` | ✅ |
| 백그라운드 동작 | 포그라운드 서비스 | ✅ |
| (부가) 가족이 보낸 장소로 목적지 변경 | NaviHelper `requestRoute`, `requestRouteWithWaypoints` | ✅ |
| (부가) "응 / 아니 / 전화해 줘" 인식 | Pleos SpeechToText (`ON_DEVICE`) | ✅ |
| (부가) 차량 위치, 시동 감지, 전화 걸기 | NaviHelper 위치 정보, AAOS `IGNITION_STATE`, 통화 인텐트 | 확인 예정 |

### 제약과 대응
| 제약 | 대응 |
|---|---|
| 졸음을 직접 판단하는 API는 실차 특수 권한 | 졸음 감지가 아니라 **연속 주행 시간 기준 휴식 권유**. 일정 시간 이상이면 무조건 한 번 권하는 하한선 |
| 차로 정보 API가 없음 | "몇 차로로"가 아니라 남은 시간 기준으로 **미리** 알리고, 깜빡이·조향으로 반응을 확인 |
| 단일 경로 정책 | 길 안내는 내장 내비가 하고, 차차, 우리는 내비를 대신하지 않는 **주의 알림**만 얹음 |
| 에뮬레이터 주행 시뮬레이션 불가 | Virtual Console로 속도·깜빡이·조향을 조작하고 길목 시나리오를 재생해 시연 |
| 주행 중 성능 기준 | 이벤트 기반으로 동작하고 녹음 보정은 서버에서 처리 |

### 일정
| 단계 | 산출물 |

## 6. 기대효과 및 발전 가능성

### 사용자에게 주는 가치
- **운전자**: 익숙한 길에서도 꼭 빠져야 할 출구와 분기점을 놓치지 않습니다. 급차로 변경 없이 여유 있게 움직이고, 멍해질 때 쉬어 갈 계기가 생깁니다
- **가족**: 녹음 몇 마디로 운전하는 가족의 안전에 함께합니다. 부가 기능으로 운전 중인지 걱정하지 않고 말을 건넬 수 있습니다
- **사회**: 고속도로 진출입부 급차로 변경과 휴식 없는 장시간 운전을 줄이는 데 도움이 됩니다

### 타깃 고객
| 구분 | 대상 | 이유 |
|---|---|---|
| 1차 | 고속도로로 출퇴근하는 운전 경력이 긴 40~50대 | 같은 길을 매일 다녀 안내에 가장 익숙해진 운전자. 신차 구매가 많은 세대로 Pleos Connect 탑재 신차를 먼저 만납니다(내연기관 신차는 50대·40대 순, 전기차는 40대가 가장 많이 구매, 2025년 상반기 보도 기준) |
| 2차 | 장거리 운전이 잦은 운전자, 부모님이 운전하는 가족, 초보 운전 자녀가 있는 가족 | 휴식 권유와 길목 안내가 그대로 필요하고, 가족이 걱정하는 운전자가 넓어집니다 |

### 예상 MAU (국내, 출시 후 약 2년 시점 추정)
현대차그룹은 Pleos Connect를 2030년까지 현대·기아·제네시스 약 2,000만 대에 적용할 계획입니다(그룹 발표 기준). 국내 신차 등록은 2025년 약 169만 대입니다.

| 항목 | 값 | 근거 |
|---|---|---|
| 국내 Pleos Connect 누적 탑재 차량 | 150만 대 | 연 국내 신차 169만 대 중 그룹 차량에 차례로 확대 적용된다고 보고 2년 누적을 보수적으로 잡음 `[가정]` |
| 40~50대 주 운전자 비율 | 50% | 신차 구매 상위 연령대(보도 기준) |
| 설치율 | 5% | 앱 마켓 개별 설치를 가정한 보수적 값 `[가정]` |
| 월 1회 이상 사용률 | 70% | 경로를 켜고 달리면 저절로 동작해 따로 켤 필요가 없음 `[가정]` |
| **운전자 MAU** | **약 2.6만 명** | 150만 × 50% × 5% × 70% |
| 연결된 가족 | 운전자 1명당 2명, 월 사용 60% | 멘트 녹음과 부가 기능(메시지, 출발·도착 알림) `[가정]` |
| **가족 MAU** | **약 4.5만 명** | 3.75만 설치 × 2명 × 60% |
| **합계 MAU** | **약 7만 명** | |

※ 2030년 글로벌 탑재 목표 2,000만 대에 같은 비율을 적용하면 운전자 MAU 약 35만 명, 가족 포함 약 95만 명입니다.

### Retention (목표와 근거)
| 지표 | 목표 | 근거 |
|---|---|---|
| 운전자 30일 유지율 | 60% | 따로 켤 필요 없이 경로를 켜고 고속도로를 탈 때마다 동작합니다. 알림을 늘리지 않아 끄고 싶어질 이유가 적습니다 |
| 가족 30일 유지율 | 50% | 부가 기능(메시지, 출발·도착 알림)이 가족이 앱을 열 이유가 됩니다 |
| 90일 유지율 | 40% | 녹음해 둔 가족 멘트는 다른 앱으로 옮길 수 없는 우리 가족만의 알림이라, 쓸수록 바꾸기 어려워집니다 |

### 수익 모델
- 기본 기능(길목 안내, 휴식 권유, 멘트 네 개) 무료
- 가족 프리미엄 구독: 상황별 멘트 여러 벌, 여러 가족 목소리, 인사 영상 저장 용량
- 차량 커넥티드 서비스 패키지에 포함
- 보험 안전운전 연계(운전자 본인이 동의할 때만, 운전 데이터 마케팅 사용 금지 준수)
