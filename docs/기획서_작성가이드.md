## 4. 접수양식 02 항목별 초안

### 1. 앱 한 줄 소개
> 혼자 운전하는 부모님 곁에서, 자녀가 직접 녹음한 목소리로 고속도로 출구·갈림길을 한 박자 먼저 알려 주고, 놓쳐도 "괜찮아 엄마"라고 다시 이끌어 주는 Pleos Connect 차량 앱

### 2. 기획 배경 (니즈·불편한 순간, 왜 해결해야 하나)
- **불편한 순간**: 처음 가는 길, 고속도로 출구나 갈림길을 늦게 알아챈 순간 → 급한 차선 변경, 갓길 정차, 길을 놓친 뒤의 당황
- **왜 고령 운전자인가**
  - ⚠️ 2025년 65세 이상 가해 사고 4만 5,873건(전체의 23.6%), 전체 사고는 1.3% 감소했는데 고령 가해 사고는 8.3% 증가 (보도 인용, TAAS 원문 확인 필요)
  - 인지 반응 능력은 70세 이후 뚜렷하게 저하, 사고와 직결되는 건 반응 속도·상황 인식·위험 판단 (연구 보도)
  - 고령 운전자에게 고속도로 합류·진출입 구간과 터널이 가장 위험 (한국도로학회 2018 연구, 원문 확인 필요)
- **기존 해결책의 한계**
  - 내비 안내는 길고 빠르다 ("300미터 앞 우측 방향 ○○ 방면 진출 후…") → 한 번에 알아듣기 어려움
  - 화면·HUD 숫자를 보려면 시선을 뺏김
  - 모든 회전을 같은 목소리로 안내 → 중요한 순간이 묻힘
- **사회적 맥락**: 면허 반납 논의는 커지지만, 병원·장보기 등 이동은 계속 필요(특히 대중교통이 부족한 지역). 자녀는 걱정하지만 "그만 운전하시라"고 말하기 어렵다 → **운전을 계속하도록 돕는 자립 지원**이 필요

### 3. 앱 주요 기능 및 차량 특화 요소
| 기능 | 설명 | 차량 특화 |
|---|---|---|
| **한 박자 먼저 알림** | 경로 전체 길목 중 놓치면 위험한 곳(출구·진입·갈림길)만 골라, 남은 시간(거리÷속도)에 맞춰 준비→재촉 단계로 알림. 고령자는 더 일찍 | NaviHelper TBT(경로 전체), 차량 속도 |
| **반응하면 즉시 멈춤** | 출구 쪽 깜빡이·조향 변화·크루즈 해제를 감지하면 알림 중단, 그 길목은 다시 안 울림 | TurnSignal, SteeringWheel, DrivingMode |
| **"괜찮아 엄마" 재안내** | 놓칠 상황이면 재촉을 멈추고 다음 출구로 차분히 안내 → 무리한 끼어들기 방지 | TBT 재탐색 이벤트 |
| **가족 목소리 멘트** | 자녀가 고정 멘트 10개를 녹음 ("엄마, 곧 오른쪽으로 나가야 해", "괜찮아 엄마, 다음에서 나가면 돼"). 미녹음은 기본 음성. 숫자 없는 짧은 문장 | 차량 오디오(내비 안내 컨텍스트, 음악은 잠깐만 줄임) |
| **빛으로 주의 환기** | 실내 앰비언트 조명 색·밝기·깜빡임으로 "지금 중요한 순간"을 알림 | Light(앰비언트) |
| **가족 음성 메모** | 자녀가 목적지와 함께 남긴 말을 **정차한 순간에만** 재생 ("진료 잘 받고 와", "약국에서 약 챙겼지?") | 도착·경유지 도착 이벤트 + 기어 P |
| **오늘의 운전** | 정차 후 칭찬 중심 요약, 점수 없음 | 도착 이벤트, 주행 규제(정차 중에만 화면) |
| **가족 연동** | 자녀 휴대폰에서 녹음, 목적지·메모 보내기, 도착 알림 (본인이 켤 때만) | NaviHelper `requestRoute` |
- **새로운 경험**: 내비가 "길"을 알려 준다면, 이 앱은 **"지금이 중요한 순간"을 가족의 목소리로** 알려 준다. 주행 중에는 화면을 보지 않게 하고, 정차한 순간에만 가족이 곁에 있는 느낌을 준다.

### 4. 주요 사용 시나리오
- **사람**: 72세 어머니(30년 운전, 요즘 반응이 느려진 걸 느낌), 45세 딸(다른 지역 거주)
- **장면 1 — 준비**: 딸이 휴대폰으로 멘트를 녹음하고 "병원→약국" 경로와 메모를 보냄
- **장면 2 — 출발**: 차에 타면 경로가 와 있음. 화면에 "오늘 알려 드릴 곳: 오른쪽 출구 한 곳". 딸 목소리 "엄마, 조심히 다녀와"
- **장면 3 — 출구**: 90초 전 "엄마, 곧 오른쪽으로 나가야 해" + 실내 조명. 어머니가 깜빡이를 켜자 바로 조용해짐
- **장면 4 — 놓침**: 다른 출구에서 반응이 없자 "엄마, 지금 오른쪽!" → 너무 가까워지자 "괜찮아 엄마, 다음에서 나가면 돼"
- **장면 5 — 도착**: 기어 P → "엄마, 진료 잘 받고 와". 오늘의 운전 "길목 다섯 곳을 잘 지나셨어요"
- **장면 6 — 다시 출발 전**: "약국에서 약 챙겼지?" / 딸에게 "어머니가 도착하셨어요"
- **딸의 하루**: "잘 도착했어?" 대신 "병원 어땠어?"로 대화가 바뀜

### 5. 개발 계획 (Pleos Connect 구현, SDK/API 사용 계획)
- **구조**: 차량 앱(Kotlin, Android Automotive) — 백그라운드 서비스가 이벤트를 받아 판단 엔진이 출력 결정 / 정차 화면 / 자녀용 휴대폰 앱 + 서버(가족 기능)
- **SDK·API 사용표** (모두 에뮬레이터 실측 — `길목도우미_통합정리.md` 6장)
| 용도 | API | 실측 |
|---|---|---|
| 경로 전체 길목 | NaviHelper `onTBTInfo` (TurnType·구간 거리·설명) | ✅ 판교→서울역 14개 |
| 경로 상태·도착·재탐색 | `onRouteStarted`, `onDestinationArrived`, `onWayPointArrived`, `onReRouteEnded` | ✅ |
| 목적지·경유지 받기 | `requestRoute`, `requestRouteWithWaypoints` | ✅ |
| 깜빡이 | Vehicle `TurnSignal` | ✅ 백그라운드 포함 |
| 조향각 | Vehicle `SteeringWheel` | ✅ |
| 크루즈 | Vehicle `DrivingMode` | ✅ (ACTIVATED) |
| 실내 조명 | Vehicle `Light` 앰비언트 색·밝기 | ✅ (차 전체 한 구역) |
| 속도·기어·주행 규제 | AAOS `PERF_VEHICLE_SPEED`, `GEAR_SELECTION`, `CarUxRestrictions` | ✅ |
| 멘트 재생 | Android 오디오 (`ASSISTANCE_NAVIGATION_GUIDANCE`, `GAIN_TRANSIENT_MAY_DUCK`) | ✅ 포커스 허용 |
- **판단 엔진**: 남은 시간 = 남은 거리 ÷ 속도 / 대기(>90초)·준비(≈90초)·재촉(≈40초)·재안내(<10초) / 해제 조건 / 시점 보정 / 예외 처리 (⚠️ 시간 값은 예시, 근거로 조정)
- **개발 일정**
  - 1차 제출까지: 판단 엔진, TBT 시나리오 재생 모드, 멘트 재생기, 오늘의 운전 화면, 시연 영상
  - 2차 PT까지: 첫 설정, 가족 음성 메모, 자녀 휴대폰 화면(목업 → 가능하면 간단한 서버), 예외 처리 다듬기
- **한계와 대응 (정직하게)**
  - 차로 정보 API 없음 → 차선 수가 아닌 **시간·운전자 반응**으로 판단. 차로·ADAS 데이터가 열리면 정확도 향상
  - 조명이 차 전체 한 구역 → 조명은 방향이 아니라 주의 환기, 방향은 소리·멘트로
  - TTS 미제공 → 가족 녹음 + 기본 녹음 음성 (오히려 핵심 기능이 됨)
  - 에뮬레이터 주행 시뮬레이션 불가 → 실제 TBT 데이터를 재생하는 시연 모드
- **정책 대응**: 앱 카테고리 Mobility Services, "길 안내"가 아닌 "주의 신호"(단일 경로 정책), 비공식 API 미사용, 주행 중 운전과 무관한 알림 없음, CPU 5% 미만 이벤트 기반 구조

### 6. 기대효과 및 발전 가능성
- **사용자 가치**: 부모님 — 처음 가는 길도 덜 긴장, 계속 운전할 자신감 / 자녀 — 걱정 대신 참여, "잔소리" 대신 목소리
- **사회적 효과**: 고령 운전자 진출입 구간 급차선 변경 감소, 면허 반납 압박과 이동권 사이의 대안
- **타깃 분석**: 1차 — 신차(Pleos 탑재)를 모는 65세 이상과 그 자녀 / 2차 — 초보 운전자, 렌터카 여행자
- **예상 MAU** (근거 수집 후 채움): `Pleos 탑재 차량 수 × 65세 이상 주 운전자 비율 × 설치율 × 월 1회 이상 경로 안내 사용률`
- **Retention 논리**: 경로 안내 시 자동 동작(앱을 따로 켤 필요 없음), 가족이 계속 들어올 이유(새 멘트, 손주 목소리, 목적지·메모 보내기), 쓸수록 맞춰지는 길목 기억
- **수익 모델**: 기본 무료 / 가족 기능 구독(자녀 결제) / 보험사 고령자 안전 특약(본인 동의, 마케팅 사용 금지 준수) / 지자체 고령 운전자 지원 사업
- **확장**: 초보 운전자 모드, 렌터카 모드, 졸음쉼터 직전 휴식 권유, 차로·ADAS 데이터 연동, 손주 목소리

## 6. 표현 규칙

- "노인" 대신 **"부모님", "고령 운전자"**
- "감시", "관리", "점수", "등급" 쓰지 않기 → **"곁에서", "안심", "칭찬"**
- "길 안내 앱", "내비"라고 부르지 않기 → **"주의 신호", "결정적인 순간 알림"** (단일 경로 정책 대응)
- 미확인 숫자는 "보도 기준", "예시"라고 표시하거나 근거 확인 후 사용
- 기능을 나열하지 말고 **장면 하나(출구 → 깜빡이 → 조용해짐)를 깊게**
- 개인정보가 02(기획서)·첨부·링크에 나오지 않게

## 7. 예상 질문과 답

| 질문 | 답 |
|---|---|
| 내비 옵션 하나 아니냐? | 내비는 모든 회전을 같은 무게로 안내한다. 우리는 **정보 안내와 행동 신호를 분리**하고, 결정적인 순간에만 가족 목소리로, 운전자 반응을 보고 멈추는 **판단 레이어**다 |
| 가족 목소리 안내는 웨이즈에도 있지 않나? | 웨이즈는 모든 안내(39개 문장)를 바꾸는 음성 팩. 우리는 결정적 순간 10개 멘트, 놓친 뒤 안심시키는 말, 부모-자녀 관계를 위한 설계. 오히려 가족 목소리 수요가 검증된 사례 |
| 자율주행이 나오면 필요 없지 않나? | 현재 운전자 보조는 운전자가 계속 지켜봐야 하고, 그런 기능이 없는 차가 대부분. HDA2 자동 차로 변경도 운전자가 깜빡이로 시작하므로 함께 처리. 확장으로 "차가 운전을 넘길 때 깨우기" |
| 몇 차로에 있는지 알 수 있나? | 현재 SDK에 차로 정보가 없다. 그래서 차로 수가 아니라 **남은 시간과 운전자 반응**으로 판단한다. 차로·ADAS 데이터가 열리면 하드웨어 추가 없이 정확도가 오른다 |
| 왜 진동이 아니냐? | 시트 진동 API가 없다(실측). 소리·멘트·조명으로 대체하고, 진동은 API가 열리면 추가 |
| 주행 중에 음성이 오히려 방해 아닌가? | 결정적 순간에만, 숫자 없는 짧은 한 문장. 생활 메모는 정차 중에만. 음악은 끄지 않고 잠깐만 줄인다 |
| 부모님이 감시당한다고 느끼지 않나? | 가족 공유는 본인이 켜야 동작, 점수 없음, 칭찬 중심. 목적은 감시가 아니라 계속 운전하실 수 있게 돕는 것 |
| 실제로 구현되나? | 에뮬레이터에서 필요한 API를 모두 호출해 확인했다(실측표). 주행 시뮬레이션만 불가해서 실제 TBT 데이터 재생으로 시연 |
| 돈은 어떻게 버나? | 자녀 결제 가족 구독, 보험 안전 특약(본인 동의), 지자체 고령 운전자 지원 사업 |
