## 3. 핵심 메시지 (어디에나 반복)

- **이름**: 차차, 우리 (영문 부제 **Bye & By, Us** — 아침의 bye, 저녁의 by and by)
- **대표 문구 (GitHub 설명과 같음)**: "차차, 우리 — 가족의 목소리를 태워 드립니다. 운전하는 동안에도 늘 가족이 곁에 있는 차량 앱"
- **두 축**: 가족의 목소리가 두 가지 방식으로 차에 탄다
  - **소통** — 가족이 보낸 목소리: 언제든 보내면, 운전 중엔 바로 / 아니면 시동 켤 때. 장소가 있으면 "응" 한마디로 목적지
  - **안전** — 가족이 미리 녹음한 목소리: 꼭 핸들을 움직여야 하는 순간(출구·분기점)과 쉬어야 할 때만
- **핵심 구조**: **가족이 먼저 다가오고, 운전자는 듣고 "응"만 한다.** 음성으로 차를 조작하는 앱이 아니다
- **슬로건 후보**: "차차, 우리. 가족이 옆자리에 탑니다" / "운전대는 그대로, 가족은 곁에" / "가족이 고른 저녁이 아빠의 목적지가 됩니다" / "꼭 들어야 할 말은, 가족 목소리로"
- **이야기 한 문단**:
  > 아빠는 매일 저녁 한 시간을 혼자 운전해 집에 옵니다. 낮에 딸은 "오늘 치킨 먹자"를 말하고 싶었지만, 아빠가 일하는 중이라 미뤘습니다. 운전 중인 아빠에게는 더더욱 연락하기 어렵습니다. 아빠는 신호 대기 때 몰래 휴대폰을 보고, 고속도로에서는 끝없는 구간단속 안내 사이에서 빠져야 할 출구를 놓쳐 급하게 차선을 바꿉니다.
  > 이제 아빠가 집으로 출발하면 가족에게 출발 알림이 갑니다. 알림을 본 딸이 치킨집을 붙여 음성 메시지를 보내면, 운전 중인 아빠에게 딸의 목소리가 들리고 "응" 한마디로 목적지가 치킨집이 됩니다. 고속도로 출구가 다가오면 딸 목소리가 "아빠, 이번에 오른쪽으로 나가야 돼" 하고 알려 줍니다. 휴대폰을 보지 않아도, 가족이 옆자리에 탑니다.
- **원칙 세 가지**: 가족이 먼저 다가온다 / 운전자는 듣고 "응"만 / 중요한 순간에만 가족 목소리

## 4. 접수양식 02 항목별 초안

### 1. 앱 한 줄 소개
> 가족의 목소리를 태워 드립니다. 가족이 언제든 보낸 음성·글 메시지를 운전 중엔 소리로 바로, 아니면 시동을 켤 때 들려주고, 메시지에 장소가 있으면 "응" 한마디로 내비 목적지를 바꿉니다. 고속도로에서는 꼭 빠져야 할 출구와 쉬어야 할 때만 가족이 녹음한 목소리로 알려 주는 Pleos Connect 차량 앱입니다.

### 2. 기획 배경 (니즈·불편한 순간, 왜 해결해야 하나)
- **불편한 순간 1 — 운전 중엔 가족과 끊긴다**: 운전 중 가족 메시지가 오면 무시하거나, 신호 대기 중에 휴대폰을 집어 든다. 가족은 운전 중일까 봐 연락을 미루고, 낮에 하고 싶던 말("오늘 치킨 먹자")은 퇴근 무렵엔 잊힌다
- **불편한 순간 2 — 중요한 안내가 묻힌다**: 고속도로에서는 구간단속·제한속도 같은 안내가 계속 나와서, 정작 차선을 바꾸거나 출구로 빠져야 할 안내를 놓친다. 그래서 급하게 차선을 바꾸다 위험해진다
- **왜 40~50대 운전자와 가족인가**
  - 출퇴근 운전 시간이 길고 신차 주 구매층 (근거 A1·C2)
  - 운전 중 휴대폰 확인은 사고 위험을 크게 높이고 법으로 금지 (근거 A3·B2·F5)
  - 고속도로 진출입부·분기점 급차로 변경 사고, 졸음·장시간 운전 위험 (근거 A8·A4·A6)
  - 가족 대화 시간이 짧고 그중 아빠와 자녀의 대화가 가장 적다 (근거 A5)
- **기존 해결책의 한계**
  - Android Auto·CarPlay는 메시지를 **읽어 주기만** 한다. 운전 중이 아닐 때 온 메시지를 시동 때 전해 주지 않고, "치킨 먹자"를 경로에 넣으려면 운전자가 직접 검색해야 한다
  - 위치 공유 앱은 휴대폰을 상시 추적해 "감시" 느낌이다
  - 내비 안내는 모든 안내가 같은 목소리·같은 무게라 중요한 안내가 묻힌다. 차량 경고음은 익숙해지면 무시하게 된다
  - 휴식 안내도 같은 무게라, 오래 달려 멍한 상태에서는 "휴게소네" 하고 흘려듣는다

### 3. 앱 주요 기능 및 차량 특화 요소
| 기능 | 설명 | 차량 특화 |
|---|---|---|
| **언제든 보내는 가족 메시지** | 가족은 언제든 음성·글 메시지를 보내고, 원하면 장소를 붙인다 | (가족 앱) |
| **운전 중엔 바로, 아니면 시동 켤 때** | 운전 중이면 화면 없이 소리로 바로(글은 TTS로 읽음). 운전 중이 아닐 때 온 메시지는 모아 뒀다가 시동 직후 인사 영상과 함께 | 기어·주행 규제, 시동, TTS |
| **"응" 한마디로 목적지** | 장소가 있으면 "OO치킨을 목적지로 할까요?" → [예] [아니요] [전화하기]. 말로 해도 같은 동작 | STT, NaviHelper `requestRoute` |
| **전화하기** | 대화가 필요하면 메시지를 보낸 가족에게 바로 핸즈프리 통화 | 차량 통화 |
| **차에서만 시작하는 위치 공유** | 목적지가 집이나 가족이 보낸 장소면 출발 때 "가족에게 위치 공유할까요?". 도착하면 자동 종료. 가족 앱에는 위치 요청 기능이 없다 | 경로 시작·도착 이벤트, 기어 |
| **중요한 길목엔 가족 목소리** | 경로의 고속도로 출구·분기점만 골라, 남은 시간에 맞춰 차 안내 "판교 IC 출구예요" 바로 뒤에 가족 목소리 "아빠, 이번에 오른쪽으로 나가야 돼"를 이어 한 번의 안내로. 깜빡이를 켜면 멈추고, 놓치면 "괜찮아, 다음에서 나가면 돼" | NaviHelper 길목 정보(TBT), 속도, 깜빡이·조향 |
| **가족 목소리 휴식 권유** | 쉬지 않고 오래 달리면 다음 졸음쉼터 전에 "오래 달렸네, 쉬었다 가자". 흘려듣던 휴식 안내를 익숙한 목소리로 깨운다 | 속도·기어, 길목 정보(쉼터) |
| **인사 영상** | 시동 직후와 집 도착 후(기어 P)에 가족 영상. 기어 D로 바꾸면 즉시 멈춤 | 기어, 도착 이벤트, 주행 규제 |
| **가족 앱** | 메시지·장소 보내기, 위치 보기, 인사 영상 올리기, 멘트 네 개 녹음 | (휴대폰 + 서버) |
- **새로운 경험**: 메신저가 "글"을 전한다면, 차차, 우리는 **가족의 목소리를 차에 태운다**. 가족이 먼저 건넨 말이 "응" 한마디로 목적지가 되고, 가장 중요한 순간엔 내비 안내 사이에서 딸 목소리가 들린다. 내비가 차량·도로 정보를 준다면, 차차, 우리는 가족이 곁에 있다는 느낌을 준다.

### 4. 주요 사용 시나리오
- **사람**: 52세 아빠(회사원, 편도 1시간 운전), 22세 딸 지은(대학생), 50세 아내
- **장면 1 — 낮, 아내가 남긴 말**: 아내가 "여보, 저녁에 비 온대. 우산 챙겨 와"를 보낸다. 아빠는 일하는 중이라 메시지는 차에 모아 둔다
- **장면 2 — 퇴근, 시동**: 시동을 켜자 딸 인사 영상 "아빠 오늘도 고생 많았어~" → "아내가 낮에 음성 메시지를 보냈어요" → 아내 목소리
- **장면 3 — 출발**: 내비에 집을 찍고 출발하자 "가족에게 위치 공유할까요?" → "응" → 가족 휴대폰에 "아빠가 출발했어요"
- **장면 4 — 운전 중 장소 메시지**: 출발 알림을 본 딸이 OO치킨을 붙여 "아빠 오늘 치킨 먹자~" → "OO치킨을 목적지로 할까요?" → "응" → 내비 목적지 변경
- **장면 5 — 운전 중 묻는 메시지**: 아내가 "마트 왔는데 두부 살까 콩나물 살까?" → "아내에게 전화할까요?" → "전화해 줘" → 핸즈프리 통화
- **장면 6 — 고속도로 출구**: 구간단속·제한속도 안내와 별개로, 출구 2km 전에 차가 "판교 IC 출구예요"라고 하고 바로 이어서 딸 목소리가 "아빠, 이번에 오른쪽으로 나가야 돼. 미리 차선 옮겨 두자" (한 번의 안내) → 여유 있게 차선을 옮기고 깜빡이를 켜자 끝
- **장면 7 — 집 도착**: 치킨을 들고 집 도착, 기어 P → 아내 영상 "오늘도 고생했어", 위치 공유 자동 종료, 가족에게 "아빠가 집에 도착했어요"
- **다른 날 — 휴식 권유** (주말 장거리로 짧게): 오래 달리다 쉼터가 다가오자 "아빠, 오래 달렸네. 다음 쉼터에서 쉬었다 가자"
- **가족의 하루**: "운전 중이야?"를 걱정하던 연락이 "오늘 치킨 먹자"로 바뀐다. 아빠는 오가는 길 내내 가족과 함께 있는 느낌

| 안내 음성·글 낭독 | Pleos TextToSpeech (`ON_DEVICE`) | ✅ |
| "응/아니/전화해 줘" | Pleos SpeechToText (`ON_DEVICE`) | ✅ |
| 가족 목소리 재생 | Android 오디오 포커스 | ✅ |
| 차량 위치, 시동 감지, 전화 걸기 | NaviHelper·AAOS·통화 인텐트 | ⬜ |
- **개발 일정**
  - 1차 제출까지: 기획서, 화면 시안
  - 2차 PT까지: 차량 앱(메시지 수신·안내·묻기, 길목 안내, 휴식 권유), 가족 앱 핵심 화면, Firebase, 시연 영상
- **한계와 대응 (정직하게)**
  - 졸음을 직접 알 수 있는 API가 없음(운전자 카메라·주의 경고는 실차 특수 권한) → 졸음 감지가 아니라 연속 주행 시간 기준의 **휴식 권유**로 설계
  - 차로 정보 API가 없음 → "몇 차로로 가라"가 아니라 남은 시간 기준으로 **미리** 알리고, 운전자 반응(깜빡이)을 보고 멈춤
  - 에뮬레이터 주행 시뮬레이션 불가 → Virtual Console로 차량 신호 조작 + 길목 시나리오 재생
- **정책 대응**: 주행 중 화면 없음·질문은 하나, 운전자가 "응" 해야만 실행, 길 안내는 내장 내비에 요청만(단일 경로 정책), 길목 안내는 내비를 대신하지 않는 주의 알림, 위치는 차에서 시작하고 도착 시 종료, 비공식 API 미사용, 무거운 처리는 서버(CPU 5% 미만)

### 6. 기대효과 및 발전 가능성
- **사용자 가치**: 운전자 — 휴대폰을 보지 않고 가족 메시지를 듣고, 중요한 출구는 가족 목소리로 놓치지 않음 / 가족 — 운전 중일까 걱정하지 않고 언제든 말을 건넴, 장소를 보내면 목적지가 됨
- **사회적 효과**: 운전 중 휴대폰 사용 감소, 고속도로 진출입부 급차로 변경 감소, 장시간 운전 휴식 유도
- **타깃 분석**: 1차 — Pleos 탑재 신차로 출퇴근하는 40~50대와 가족 / 2차 — 부모님 운전 가족, 초보 운전 자녀, 장거리 운전이 잦은 가족
- **예상 MAU** (근거 수집 후 채움): `Pleos 탑재 차량 수 × 40~50대 주 운전자 비율 × 설치율 × 월 1회 이상 사용률` + 연결된 가족 수
- **Retention 논리**: 출퇴근마다 자동 동작, 시동 때마다 쌓인 가족 메시지·영상, 출발 알림이 오면 가족이 앱을 연다, 고속도로에서는 길목 안내가 계속 쓰인다, 사용자가 가족 전체
- **수익 모델**: 기본 무료 / 가족 프리미엄 구독(가족 수, 영상 저장, 멘트 여러 벌) / 커넥티드 서비스 패키지 / 보험 안전운전 연계(본인 동의, 마케팅 사용 금지 준수)
- **확장**: 개인 운전 습관 학습으로 휴식 권유 고도화, 가족 목소리 음성 합성, 공조 제안, 시내 큰 갈림길 안내, 부모님 운전·초보 운전 모드

### 7. 참고자료 (가산점)
- 시연 영상: 에뮬레이터(차량 앱) + 휴대폰(가족 앱) 화면 녹화, 4장 시나리오 흐름

### 8. 숏폼 (선택)

## 6. 표현 규칙

- "위치 추적", "감시", "모니터링" 쓰지 않기 → **"운전자가 보내 주는 위치", "공유", "안심"**
- "졸음 감지"라고 쓰지 않기 → **"휴식 권유"**, "차량 기본 안전 기능을 대신하지 않음". "조는 거 아니지?", "일어나!"처럼 의심하거나 다그치는 말 쓰지 않기
- 길목 안내는 **"내비 안내를 대신하지 않는 주의 알림"**. "길 안내 앱"이라고 부르지 않기 (단일 경로 정책)
- "메신저 앱"이라고 부르지 않기 → **"가족의 목소리를 태워 주는 차량 앱"**
- "AI가 차를 조작한다"고 쓰지 않기 (항상 운전자 "응")
- 미확인 숫자는 "보도 기준", "예시"라고 표시하거나 근거 확인 후 사용
- 기능을 나열하지 말고 **장면 둘을 깊게**: 소통(출발 알림 → "치킨 먹자" → "응"), 안전(구간단속 안내 사이 "아빠, 이번에 오른쪽으로 나가야 돼")
- 주어는 **가족**으로. "운전자가 음성으로 목적지를 바꾼다"(음성 비서처럼 들림)가 아니라 "가족이 보낸 장소로 아빠가 향한다"
- 개인정보가 02(기획서)·첨부·링크에 나오지 않게 (시연 영상 속 가족 얼굴·이름 포함 주의)

## 7. 예상 질문과 답

| 질문 | 답 |
|---|---|
| Android Auto 메시지 읽기와 뭐가 다른가? | 그건 운전자가 기능을 쓰는 구조이고, 지금 온 메시지만 읽어 준다. 우리는 **가족이 먼저 다가온다**. 운전 중이 아닐 때 온 말도 시동 때 전하고, 장소는 "응" 한마디로 목적지가 된다. 그리고 고속도로의 중요한 순간엔 가족 목소리로 알린다 |
| 소통 앱과 안전 앱이 섞인 것 아닌가? | 둘 다 **"가족의 목소리를 차에 태운다"**는 한 가지다. 가족이 지금 보낸 목소리(소통)와 미리 녹음해 둔 목소리(안전). 같은 가족 앱에서 보내고 녹음한다 |
| 내비가 이미 출구를 알려 주지 않나? | 알려 준다. 문제는 구간단속·제한속도 같은 안내와 **같은 목소리, 같은 무게**라 묻힌다는 것. 안내를 늘리는 게 아니라, 꼭 핸들을 움직여야 할 순간만 **다른 목소리(가족)**로 다르게 들리게 한다. 차 안내 바로 뒤에 가족 목소리를 이어 붙여 한 번의 안내로 들리고, 깜빡이를 켜면 바로 멈춘다 |
| 휴식 안내도 이미 있지 않나? | 있다. 하지만 같은 무게의 안내라 멍한 상태에서는 흘려듣는다. 익숙한 가족 목소리가 "쉬었다 가자"고 하면 그때 정신이 든다 |
| 가족이 차를 마음대로 조종하는 것 아닌가? | 가족은 **제안만** 한다. 목적지 변경·위치 공유는 운전자가 "응" 해야만 실행한다 |
| 위치 공유가 감시 아닌가? | 가족 앱에는 위치 요청 기능이 없다. **차에서 운전자가 시작할 때만** 공유되고, 도착하면 자동으로 끝난다 |
| 졸음을 알 수 있나? | 졸음을 판단하지 않는다. 쉬지 않고 달린 시간·시간대 기준으로 **쉼터 전에 쉬어 가자고 권할 뿐**이다. 연속 일정 시간 이상이면 무조건 한 번 권하는 안전 하한선을 둔다 |
| 음성인식이 안 되면? | 큰 버튼 셋(예 / 아니요 / 전화하기)을 함께 둔다. 응답이 없으면 "나중에"로 넘기고 메시지함에 남긴다 |
| TTS·STT는 쓸 수 있나? | Pleos TextToSpeech·SpeechToText의 `ON_DEVICE` 모드를 에뮬레이터에서 실측했다. 신청·앱 등록 없이 한국어 낭독·인식이 된다 |
| 돈은 어떻게 버나? | 가족 프리미엄 구독, 커넥티드 서비스 패키지, 보험 안전운전 연계(본인 동의) |
