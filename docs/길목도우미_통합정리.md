## 1. 한 줄 소개

**앱 이름: 엄마, 오른쪽** (2026-11-09 확정, 엄마 버전)
- 앱이 실제로 하는 말을 그대로 이름으로 썼다. **자녀가 직접 녹음한 목소리**로 "엄마, 다음에 오른쪽이야", "괜찮아 엄마, 다음 출구로 가면 돼"를 들려준다 (TTS 불가를 녹음 음성으로 대체하면서 생긴 핵심 기능)
- 후보였던 "치사랑"은 같은 컨셉의 앱("치사랑 - 부모님 일정 알림")이 이미 있어 제외. 상표는 키프리스에서 확인 필요

**"운전을 계속하고 싶은 부모님을 위해, 헷갈리는 길목을 미리 알려 주고 놓쳐도 당황하지 않게 다시 이끌어 주는 차량용 앱"**

- 감시나 면허 반납 압박이 아니라 **"계속 운전하실 수 있게 돕는 자립 지원"**
- 앱 카테고리 가정: **Mobility Services** (내비 앱이 아니라 "주의 신호" 앱. 이유는 8장)

## 2. 왜 필요한가

### 2-1. 숫자 (보도 인용, 원문 확인 필요)
- 2025년 전체 교통사고는 전년보다 1.3% 줄었는데, **65세 이상 운전자 가해 사고는 8.3% 늘어 전체의 23.6%**(4만 5,873건)
- 고령 운전자의 인지 반응 능력은 **70세 이후 뚜렷하게 저하**, 사고와 직결되는 건 시력보다 **반응 속도·상황 인식·위험 판단**
- 65세 이상에서 반응 시간이 급격히 늘어 설계 기준(2.5초) 상향이 필요하다는 연구
- 고령 운전자에게 **고속도로 합류·진출입 구간과 터널이 가장 위험한 구간**

### 2-2. 사람의 이야기
- **부모님(72세)**: 병원·장보기 때문에 운전이 꼭 필요하다. 처음 가는 길에서 출구나 갈림길을 늦게 알아채면 급하게 끼어들거나 갓길에 선다. 기존 내비 안내는 길고 빨라서 한 번에 못 알아듣는다.
- **자녀(45세)**: 걱정되지만 "운전 그만하시라"는 말은 못 꺼낸다.

### 2-3. 왜 차량 앱이어야 하나 (차량특화성)
- 판단에 **경로 전체 길목, 속도, 깜빡이, 조향, 크루즈 상태**가 필요하다. 휴대폰은 깜빡이·조향·크루즈를 모른다.
- 주행 중에는 화면을 쓰지 않고 **정차 중에만** 화면을 쓴다 → 차량 주행 규제 원칙과 일치

## 3. 설계 원칙

1. **결정적인 순간에만 개입한다**: 모든 회전이 아니라 놓치면 위험한 길목만
2. **시선을 뺏지 않는다**: 주행 중 화면 없음. 소리·빛만
3. **한 번에 한 가지 행동만**: "오른쪽으로 가세요" 수준
4. **놓치면 포기시킨다**: 무리한 끼어들기 대신 "괜찮아요, 다음 출구로"
5. **평가하지 않는다**: 점수·등급 없음, 칭찬 중심
6. **본인이 주인이다**: 가족 공유는 운전자가 켤 때만

## 4. 판단 엔진

### 4-1. 입력 (모두 에뮬레이터에서 실측 확인)
| 입력 | 출처 | 실측 |
|---|---|---|
| 경로 전체 길목(종류·구간 거리·설명) | NaviHelper `onTBTInfo` | ✅ 14개 한 번에 수신 |
| 속도 | AAOS `PERF_VEHICLE_SPEED` (m/s) | ✅ |
| 깜빡이 | Pleos `TurnSignal` | ✅ LEFT/RIGHT/OFF |
| 조향각 | Pleos `SteeringWheel` | ✅ (부호 확인 필요) |
| 크루즈 | Pleos `DrivingMode` | ⚠️ ACTIVATED만 재현 |
| 기어·주행 규제 | AAOS `GEAR_SELECTION`, `CarUxRestrictions` | ✅ |

### 4-2. 길목 중요도
| 등급 | TurnType | 알림 |
|---|---|---|
| 높음 | `TURN_EXIT_IC_*`, `TURN_ENTER_IC_*`, `TURN_DEVIDE_MERGE`, `TURN_KEEP_L/R` | 준비·재촉·재안내 |
| 중간 | 지하·고가차도(`TURN_ENTER/AVOID_UNDER/OVER_*`), 회전교차로 | 준비만 |
| 낮음 | 일반 교차로 `TURN_LEFT/RIGHT`, `TURN_TOLL`, `TURN_TUNNEL` | 기본 끔(설정으로 켬) |
- 왼쪽 출구(`*_L`)는 한 단계 일찍

### 4-3. 단계 (남은 시간 = 남은 거리 ÷ 속도, 숫자는 예시)
| 단계 | 조건 | 출력 |
|---|---|---|
| 대기 | > 90초 | 없음 |
| 준비 | ≈ 90초 | 짧은 신호 한 번 (방향 소리 + 조명 은은하게) |
| 재촉 | ≈ 40초, 반응 없음 | 점점 빨라지는 반복 신호 + 조명 깜빡임 |
| 재안내 | < 10초, 반응 없음 | 재촉 중단, "괜찮아요, 다음 출구로 안내할게요" |
- 정체(시속 10km 미만)에서는 시간 대신 거리 기준(예: 300m)

### 4-4. 해제 조건 (확정)
- 출구 방향 깜빡이 (켰다 바로 꺼도 인정)
- 출구 방향 조향 변화 (각도 + 유지 시간, 커브 오인 방지)
- 크루즈 `SUSPENDED`, `USER_OVERRIDE` (`FORCED_DEACTIVATION_WARNING` 제외)
- 길목 통과, 재탐색, 안내 종료
- **한 번 해제된 길목은 다시 울리지 않음**

### 4-5. 시점 보정 (앞당김)
- 사용자 설정 "조금/많이 일찍", 왼쪽 출구, 지난번에 놓친 길목, 교통 혼잡, 크루즈 장시간 `ACTIVATED`

### 6-3. Virtual Console 자동 조작 방법
- 먼저 `POST http://127.0.0.1:8088/browser/session?client=<임의 ID>` (안 하면 503)
- 깜빡이 `PUT /vehicle/turn-signal?mode=BlinkRight|BlinkLeft|Off`
- 조향 `PUT /vehicle/controls?steering=35`
- 속도 `PUT /vehicle/controls?speed=80` (기어 D 먼저: `PUT /vehicle/gear?gear=Drive`)
- 크루즈 `PUT /vehicle/driving-mode?ad_mode_state=full_autonomous|ready`
- 조명 `PUT /vehicle/body?ambient_brightness=40`
- 상태 확인 `GET /vehicle/state`, 전체 항목 `GET /vehicle/catalog`

## 7. PT 시연 시나리오 (실측 기반)

1. **첫 설정**: "조금 일찍", "소리+빛" 선택 (F1)
2. **출발 전**: 판교→병원 경로 요청 → 화면에 "오늘 알려 드릴 곳: 오른쪽 출구 한 곳" (E1, 실제 TBT 리스트 사용)
3. **주행 장면**: 기어 D, 속도 90km/h(콘솔) + **TBT 재생 모드로 출구까지 남은 거리 감소**
4. **준비 신호**: 90초 전 "오른쪽" 신호음 + 실내 조명 은은하게 주황색
5. **반응**: 콘솔에서 오른쪽 깜빡이 → 신호 즉시 멈춤 (B1, 실제 이벤트)
6. **두 번째 출구**: 반응 없이 진행 → 재촉(빨라지는 신호음 + 조명 깜빡임) → "괜찮아요, 다음 출구로 안내할게요"(녹음 음성)
7. **도착**: 정차 후 "오늘의 운전" 화면, 가족 알림 목업
8. **비교**: 같은 장면에서 기존 내비 음성 안내와 나란히

## 8. 정책·위험

- **단일 경로 정책**: 내비 앱은 백그라운드에서 모든 안내 금지 → "길 안내 앱"으로 분류되면 위반 소지. **Mobility Services + "주의 신호"로 정의**, 주최 측 문의
- **비공식 API 금지**: 에뮬레이터에 문서에 없는 ADAS 서비스(`ADAS_LOCAL_MAP`, `ADAS_DRIVING_WARN` 등)가 있으나 사용하지 않음. 기획서에는 "ADAS 데이터가 열리면 정확도 향상" 근거로만
- **에뮬레이터와 실차 권한 차이**: `PRIVATE_CAR_SAFETY`가 에뮬레이터에서는 normal, 문서는 signature|privileged → 경고등 기능은 확장으로만
- **개인정보**: 위치 저장 시 위치기반서비스 신고 검토, 운전 데이터 **마케팅 사용 금지** 규정 → 보험 연계는 "본인 동의 기반 안전 할인"으로 한정해 설명
- **감시·비하 인식**: 칭찬 중심, 점수 없음, 본인이 켜는 공유로 방어
- **성능 기준**: 내비 외 앱 주행 중 CPU 5% 미만, RAM 400MB 이하 → 이벤트 기반 구조로 충족

## 9. 사업성 (초안)

- B2C: 기본 무료, 가족 공유·길목 기억은 구독 또는 차량 서비스 패키지
- 보험사: 고령 운전자 안전 특약 (본인 동의 시)
- 지자체: 면허 반납 제도의 보완·대안 (조건부 면허 논의와 연결)
- 확장: 같은 엔진으로 초보 운전자 모드, 렌터카 모드
- Retention: 경로 안내 중 자동 동작(따로 실행 불필요), 가족 알림 습관화, 쓸수록 맞춰지는 길목 기억
- 필요한 숫자: 65세 이상 면허 소지자 수, Pleos 탑재 차량의 고령 소유 비율, 보험사 고령자 특약 사례
