## 1. 한 줄 소개

**앱 이름: 차차, 우리** (영문 `chacha-woori`, 패키지 `com.automoder.chachawoori`, 2026-11-13 "퇴근길"에서 변경)
- **영문 부제: Bye & By, Us** — "by and by"(차차, 머지않아)의 앞 by를 bye(안녕)로 바꾼 말장난. 아침에 "bye" 하고 헤어진 가족이 저녁에 차차 다시 만난다
- 표기: 주 이름은 한글 "차차, 우리", 영문은 부제로만. 코드·저장소·파일명은 `&`를 쓸 수 없어 `chacha-woori` 그대로
- 이름의 뜻: "차차"(점점, 시간이 흐르며) 가까워지는 "우리". 차(車) 안에서도 가족이 함께라는 느낌도 겹친다
- 상표·같은 이름 앱 여부는 키프리스·플레이스토어에서 확인 필요

**대표 문구: "가족의 목소리를 태워 드립니다. 운전하는 동안에도 늘 가족이 곁에 있는 차량 앱"**

가족의 목소리가 두 가지 방식으로 차에 탄다.

| 축 | 내용 |
|---|---|
| **소통** — 가족이 보낸 목소리 | 가족은 언제든 음성·글 메시지를 보내고, 원하면 장소를 붙인다. 운전 중이면 바로 소리로 전하고, 아니면 모아 뒀다가 시동을 켤 때 들려준다. 장소가 붙어 있으면 "목적지로 할까요?"를 묻고, 운전자는 "응" 한마디로 답한다. 대화가 필요하면 "전화하기" |
| **안전** — 가족이 미리 녹음한 목소리 | 내비 알림이 쏟아지는 고속도로에서, **꼭 핸들을 움직여야 하는 순간**(출구·분기점)과 **쉬어야 할 때**만 가족 목소리로 알린다. "아빠, 이번에 오른쪽으로 나가야 돼", "괜찮아, 다음에서 나가면 돼", "오래 달렸네, 쉬었다 가자" |

- **주인공은 가족이다.** 가족이 먼저 다가오고, 운전자는 듣고 "응" 하기만 한다 (음성 비서·음성 제어 앱이 아니다)
- **내비와 하는 일이 다르다.** 내장 내비는 차량·도로 정보를 주고, 차차, 우리는 그 위에 가족이 곁에 있다는 느낌을 얹는다
- 위치 공유는 **차에서만** 시작한다. 가족 앱에는 위치 요청 기능이 없다
- 시나리오와 PT는 "퇴근길 아빠"를 대표 장면으로 쓴다. 호칭은 예시이며, 운전하는 가족 누구에게나 해당한다
- 앱 카테고리: ⬜ (`공모전_가이드_정리.md`의 카테고리 목록에서 고른다. 후보: Mobility Services)

## 2. 왜 필요한가

### 2-1. 숫자 (모두 근거 수집 전, `근거_수집목록.md` 참고)
- 40~50대는 출퇴근 운전 시간이 길고, 신차 주 구매층이다 (A1·C2)
- 운전 중 휴대폰으로 메시지를 확인·입력하는 행동이 사고 위험을 크게 높인다 (A3·B2)
- 고속도로 진출입부·분기점에서 급차로 변경 사고가 잦다 (A8)
- 고속도로 사망 사고에서 졸음·주시 태만 비중이 높다 (A4)
- 가족 대화 시간이 짧고, 그중 아빠와 자녀의 대화가 가장 적다 (A5)

### 2-2. 사람의 이야기
- **아빠(52세)**: 회사까지 편도 한 시간 운전. 운전 중 가족 카톡이 오면 신호 대기 때 몰래 보거나 집에 와서야 확인한다. 고속도로에서 구간단속·제한속도 안내가 계속 나오다 보니, 정작 빠져야 할 출구 안내를 놓쳐 급하게 차선을 바꾼 적이 있다. 야근 뒤 밤길에 졸음이 온다.
- **딸(22세, 대학생)**: 아빠가 언제 오는지 궁금하지만 운전 중일까 봐 전화를 미룬다. 낮에 "오늘 치킨 먹자"를 말하고 싶어도 아빠가 퇴근할 때는 잊어버린다.
- **아내(50세)**: 퇴근길에 "두부 좀 사 와"를 부탁하려다 이미 집 앞이라 늦는다.

### 2-3. 왜 차량 앱이어야 하나 (차량특화성)
- 휴대폰은 **지금 운전 중인지, 시동을 켰는지, 기어가 P인지**를 모른다. 차는 안다 → 운전 중이면 소리로 바로, 아니면 시동 켤 때 전한다
- 가족이 보낸 장소를 **"응" 한마디로 차량 내비 목적지로 바꿀 수 있는 건** 차량 앱뿐이다 (NaviHelper `requestRoute`)
- **경로 전체의 길목(출구·분기점·졸음쉼터)과 깜빡이·속도**를 함께 보는 건 차량 앱뿐이다 → 중요한 순간을 골라 가족 목소리로 알리고, 운전자가 깜빡이를 켜면 바로 멈춘다
- 위치 공유를 **목적지(집)와 출발·도착 이벤트에 맞춰** 시작하고 끝낼 수 있다 → 상시 추적이 아니다
- 영상은 **기어 P일 때만**, 주행 중에는 화면 없이 소리만 → 주행 규제 원칙과 일치

## 3. 설계 원칙

1. **가족이 먼저 다가온다**: 대화를 시작하는 쪽은 가족이다. 운전자가 차에게 명령하는 구조가 아니라, 가족이 보낸 것을 받는 구조
2. **운전자는 듣고 "응"만**: 운전자가 할 일은 예 / 아니요 / 전화하기 중 하나를 말하는 것뿐. 검색·입력을 요구하지 않는다
3. **주행 중엔 귀로만**: 화면을 보거나 만질 일을 만들지 않는다. 영상은 정차 중(시동 직후, 도착 후)에만
4. **중요한 순간에만 끼어든다**: 길목 안내는 모든 회전이 아니라 놓치면 위험한 출구·분기점만. 운전자가 반응(깜빡이)하면 바로 멈춘다
5. **잔소리가 아니라 가족 목소리**: 경고음 대신 가족 목소리. "조는 거 아니지?"처럼 의심하거나 다그치는 말은 쓰지 않는다
6. **공유는 운전자가 주인**: 위치 공유는 차에서만 시작하고, 도착하면 자동으로 끝난다. "감시"가 되지 않게

## 4. 시스템 구조

```
[가족 앱 (Android, Kotlin)]  ──음성·글·장소·인사 영상·멘트 녹음──▶  [Firebase]
        ▲                                                       │  Auth / Firestore / Storage
        │ 위치·도착 예정 시간·결과 알림                           │  Cloud Functions: 녹음 보정, (보조) 장소 제안
        │                                                       ▼
        └───────────────────────────────────────────────  [차량 앱 (Pleos Connect, Kotlin)]
                                                           포그라운드 서비스: 메시지 수신·안내·묻기·실행, 길목 안내, 휴식 권유
                                                           정차 화면: 시동 때 메시지·인사 영상, 메시지함, 설정
```

- **안내 음성(TTS)**: Pleos TextToSpeech SDK `ON_DEVICE` 모드 ✅ (신청·앱 등록 불필요, 2026-11-13 실측). "지은이가 장소를 보냈어요", 글 메시지 낭독
- **음성 응답(STT)**: Pleos SpeechToText SDK `ON_DEVICE` 모드 ✅ (신청·앱 등록 불필요, 한국어 인식 확인). "응", "아니", "전화해 줘"
- **가족 목소리**: 가족이 보낸 음성 메시지와 미리 녹음한 멘트는 녹음 파일 그대로 재생
- **처리 무거운 일은 서버에서**: 녹음 보정, (보조) 장소 제안 → 차량은 재생과 SDK 호출만 (주행 중 CPU 5% 미만 기준)

## 5. 기능 목록

**우선순위** P0: 기획서·PT 핵심 / P1: 있으면 좋음 / P2: 발전 계획
**상태** ✅ 실측 동작 / ⬜ 확인 필요 / 📱 가족 앱·서버 / 🎭 시연은 대체 방식

### 소통 — 가족이 보낸 목소리

**흐름**
```
가족: 언제든 음성·글 메시지를 보냄 (원하면 장소를 붙임)
 ├ 운전 중이면 → 바로 전함
 └ 운전 중이 아니면 → 모아 뒀다가 시동을 켤 때(기어 P) 전함

차: "지은이가 장소를 보냈어요. 음성 메시지가 있어요" → 메시지 재생
   → (장소가 있으면) "OO치킨을 목적지로 할까요?"
   → [예] [아니요] [전화하기]  ← 말로 해도 같은 동작 ("응" / "아니" / "전화해 줘")
   → 예: 내비 목적지 변경, 가족 앱에 "아빠가 OO치킨으로 가요"
   → 전화하기: 핸즈프리 통화
```

#### A. 가족 메시지
| ID | 기능 | 우선 | 상태 | 비고 |
|---|---|---|---|---|
| A1 | 언제든 보내기 | P0 | 📱 | 가족 앱에서 음성 또는 글. 장소는 선택해서 붙임 (가족이 직접 검색해 고름) |
| A2 | 운전 중이면 바로 전하기 | P0 | ✅ | 짧은 알림음 → TTS로 "누가 보냈는지" → 음성은 녹음 그대로, 글은 TTS로 읽음. 화면 없음 |
| A3 | 시동 켤 때 전하기 | P0 | ⬜ 시동 감지 | 운전 중이 아닐 때 온 메시지는 모아 두었다가 시동 직후(기어 P) "메시지가 세 개 있어요" → 최근 것부터. 출발 인사 영상(C1)도 여기서 함께 |
| A4 | 묻고 실행 | P0 | ✅ | 장소가 있으면 "목적지로 할까요?" → 예 / 아니요 / 전화하기. 음성(STT)과 큰 버튼 셋 모두 |

### 5-1. D1~D4 길목 안내 (숫자는 모두 예시)
**입력** (에뮬레이터 실측 ✅): 경로 전체 길목(NaviHelper `onTBTInfo`, 종류·구간 거리), 속도(`PERF_VEHICLE_SPEED`), 깜빡이(`TurnSignal`), 조향(`SteeringWheel`)

| 단계 | 조건 | 가족 목소리 |
|---|---|---|
| 대기 | 남은 시간 > 90초 | 없음 |
| 미리 알림 | ≈ 90초 (차선을 여유 있게 옮길 수 있을 때) | 차(TTS) "2km 앞 판교 IC 출구예요." 바로 이어서 가족 "아빠, 이번에 오른쪽으로 나가야 돼" (한 번의 안내) |
| 한 번 더 | ≈ 40초, 차선 변화·깜빡이 없음 | 같은 말을 한 번 더, 차분하게 |
| 놓쳐도 괜찮아 | < 10초, 반응 없음 | 더 알리지 않고 "괜찮아, 다음에서 나가면 돼" |

- **다급하게 외치지 않는다.** 내비의 구간단속·제한속도·카메라 안내와 별개로, **차선을 바꾸거나 진입로로 나가야 하는 일을 미리** 차분하게 알려 주는 것. 출구 이름은 TTS가, "어느 쪽으로 가야 하는지"는 가족 목소리가 말한다
- **안내를 하나 더 늘리는 게 아니다.** 안내가 너무 많아 중요한 안내가 묻히니, 중요한 안내만 가족 목소리로 다르게 들리게 한다. TTS와 가족 목소리는 쉬지 않고 이어서 한 번의 안내로 들린다 → 출구는 두 번 강조되고 안내 횟수는 그대로

- **알리는 길목**: 고속도로 출구(`TURN_EXIT_IC_*`), 진입(`TURN_ENTER_IC_*`), 분기점(`TURN_DEVIDE_MERGE`, `TURN_KEEP_L/R`). 일반 교차로·톨게이트·터널은 알리지 않는다 (내비가 이미 안내)
- **멈추는 조건**: 출구 쪽 깜빡이, 출구 쪽 조향 변화, 길목 통과, 재탐색, 안내 종료. 한 번 멈춘 길목은 다시 알리지 않는다
- 정체(예: 시속 10km 미만)에서는 시간 대신 거리 기준
- 목적지 없이 달릴 때는 동작하지 않는다 (경로가 있어야 길목을 안다)
- 내비 안내를 대신하지 않는다. 내비 안내 위에 **"이건 꼭 들어"** 하는 가족 목소리를 얹는 것

### 5-2. D5 휴식 권유
- **왜 가족 목소리인가**: 기존 휴식 안내도 다른 안내와 같은 무게라, 오래 달려 멍한 상태에서는 "휴게소네" 하고 흘려듣는다. 졸린지 스스로 돌아보지도 못한 채 멍한 상태가 이어진다 → 익숙한 가족 목소리로 정신을 깨운다 (고속도로 최면 근거는 정리 예정)
- **"졸음 감지"가 아니라 "휴식 권유"**: 졸음을 직접 알 수 있는 API가 없고, 의심받는 느낌을 주지 않기 위해
- **기준**: 연속 주행 시간(정차 없이 달린 시간), 시간대(심야 등) 같은 통계 기준값으로 시작
- **안전 하한선**: 연속으로 일정 시간 이상(예: 도로공사 "2시간마다 휴식" 권고, 근거 B4) 달리면 무조건 한 번은 권한다
- **말하는 때**: 기준을 넘고 **다음 졸음쉼터·휴게소(TBT)가 다가올 때**
- **잔소리가 되지 않게**: 권유 뒤 쉬지 않으면 예: 30분 뒤 한 번만 다시. 설정은 켜고 끄기만, 시간 숫자는 보여 주지 않는다
- 판단 결과는 차 안에서만 쓰고 가족에게 보내지 않는다

### 5-3. D7 가족 녹음 멘트 (네 개)
| 상황 | 멘트 예시 | 녹음 |
|---|---|---|
| 오른쪽 출구·분기점 | "아빠, 이번에 오른쪽으로 나가야 돼" | 딸 |
| 왼쪽 출구·분기점 | "아빠, 이번에 왼쪽으로 가야 돼" | 딸 |
| 놓쳤을 때 | "괜찮아, 다음에서 나가면 돼" | 아내 |
| 휴식 권유 | "아빠, 오래 달렸네. 다음 쉼터에서 쉬었다 가자" | 딸 |

- 녹음하는 가족이 지치지 않게 **꼭 필요한 순간의 짧은 멘트만**. 숫자·장소 이름("300미터 앞", "판교 IC")은 넣지 않는다 (TTS가 말함)
- 말투는 다급하지 않게, 평소 말하듯 (예: "아빠, 이번에 오른쪽으로 나가야 돼. 미리 차선 옮겨 두자")
- 녹음하지 않은 멘트는 TTS 기본 음성으로 채운다 → 일부만 녹음해도 바로 쓸 수 있다
- 녹음 후 **자동 보정**(서버): 음량 평준화, 잡음 제거, 앞뒤 무음 자르기, 찢어짐 감지 시 다시 녹음 안내
- 개인정보: 목소리·얼굴은 개인정보 → 녹음·촬영·보관 동의

### 5-4. 메시지 전달 규칙 (A2~A4)
| 상태 | 처리 |
|---|---|
| 운전 중 | 화면 없음. 알림음 → 보낸 사람 → 음성 재생 또는 글 낭독(TTS) → (장소가 있으면) 질문 한 개 → 음성 응답 |
| 시동 직후 (기어 P) | 인사 영상 + "메시지가 N개 있어요" → 최근 것부터. 기어 D로 바꾸면 영상은 멈추고 남은 메시지는 주행 중 규칙으로 |
| 정차 중 (기어 P) | 화면 + 소리, 버튼 셋(예 / 아니요 / 전화하기) |
| 긴 글 메시지 | 주행 중에는 앞부분만 읽고 "나머지는 도착하면 보여 드릴게요" |
| 길목 안내·휴식 권유 중 | 메시지를 미뤘다가 끝난 뒤 전한다 (D6) |
| 통화 중 | 통화가 끝난 뒤 전한다 |
| 응답 없음 (예: 8초) | 한 번 더 묻고, 그래도 없으면 "나중에"로 넘기고 메시지함에 남긴다 |

## 8. 정책·표현

- **단일 경로 정책**: 길 안내를 직접 하지 않는다. 내장 내비에 목적지를 **요청만** 하고(`requestRoute`), 길목 안내는 내비 안내를 대신하지 않는 **주의 알림**으로 설명
- **위치정보**: 공유는 차에서 운전자가 시작할 때만, 도착 시 자동 종료, 기록 보관 최소화. "위치 추적"이 아니라 "운전자가 보내 주는 위치"
- **운전 데이터**: 길목 반응·휴식 권유 판단은 차 안에서만, 가족에게 자동 공유 안 함. 마케팅 사용 금지 규정 준수
- **실차 권한**: `PRIVATE_CAR_SAFETY`·`DRIVER_ATTENTION`은 실차 특수 권한 → 사용 안 함. 문서에 없는 ADAS 서비스 사용 안 함
- **성능 기준**: 주행 중 CPU 5% 미만, RAM 400MB 이하 → 이벤트 기반 + 무거운 처리는 서버

- **사용자가 둘 이상**: 운전자(차량 앱) + 가족(휴대폰 앱) → 가족이 매일 들어올 이유가 있다 (메시지, 출발 알림, 위치)
- **Retention**: 출퇴근마다 자동 동작(따로 켤 필요 없음), 시동 때마다 쌓인 가족 메시지·영상, 출발 알림이 오면 가족이 앱을 연다, 고속도로에서는 길목 안내가 계속 쓰인다
- **MAU 수식**: `Pleos 탑재 차량 수 × 40~50대 주 운전자 비율 × 설치율 × 월 1회 이상 사용률` + 연결된 가족 수
- **수익 모델**: 기본 무료 / 가족 프리미엄 구독(가족 수·영상 저장 용량·멘트 여러 벌) / 차량 커넥티드 서비스 패키지 / 보험 안전운전 연계(본인 동의 시)
- **확장**: 5장 X 항목

## 11. 결정 기록 (2026-11-13)

| 결정 | 이유 |
|---|---|
| 졸음 감지 → **휴식 권유** | 졸음을 알 API가 없고, 의심받는 느낌을 주지 않기 위해 |
| 개인 습관 학습은 발전 계획(X1)으로 | 장기 학습·도로 유형별 차이·정답 문제 |
| 장소 메시지에 **영상 제외** | 운전 중 받는 메시지라 영상은 위험. 영상은 정차 중 인사에만 |
| 장소 한마디(옛 D5) **삭제** → **시동 켤 때 쌓인 메시지 재생**으로 | 가족은 언제든 보내고, 차는 운전 중이면 바로, 아니면 시동 때 전한다 |
| 출발 인사 영상을 시동 때 전하는 것에 **합침** | "쌓여 있다가 시동 때 나오는 가족 목소리"로 한 가지 |
| 위치 공유는 **차에서만** | 가족 앱에서 요청하게 하면 프라이버시 침해 소지. 목적지가 집·가족이 보낸 장소면 출발 때 묻는다 |
| 운전자 답장 → **전화하기** | 말로 주고받을 거면 실시간 통화가 낫다. 차는 수신까지만 |
| 버튼 **예 / 아니요 / 전화하기**, 음성으로도 동작 | 운전자는 셋 중 하나만 말하면 된다 |
| **글 메시지 포함** | Pleos TTS `ON_DEVICE`가 신청 없이 동작 |
| **길목 안내를 핵심 기능으로** | "중요한 순간에만 가족 목소리"가 원래 문제의식. 차량특화성이 가장 강한 기능 |
