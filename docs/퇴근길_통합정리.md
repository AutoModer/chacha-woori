## 1. 한 줄 소개

**앱 이름: 퇴근길** (영문 `way-home`, 패키지 `com.automoder.wayhome`)
- 하루 중 아빠가 혼자 있는 가장 긴 시간인 **퇴근길을, 가족과 함께 타는 시간으로** 바꾼다는 뜻
- 상표·같은 이름 앱 여부는 키프리스·플레이스토어에서 확인 필요

**"운전 중인 아빠와 집에 있는 가족을, 휴대폰을 보지 않고도 이어 주는 차량 앱"**

- **주인공은 가족이다. 가족이 먼저 다가오고, 아빠는 듣고 "응" 하기만 한다** (음성 비서·음성 제어 앱이 아니다)
- 아빠가 퇴근 운전을 시작하면 위치가 공유되고 가족에게 "아빠 출발했어요" 알림이 간다
- 가족은 앱을 열어 아빠가 오는 것을 보고, **영상·음성 메시지에 장소를 붙여 보낸다** ("오늘 치킨 먹자" + OO치킨)
- 차는 소리로 전한다: "지은이가 장소를 보냈어요. 음성 메시지가 있어요" → 메시지 재생 → "목적지를 OO치킨으로 바꿀까요?" → 아빠 "응" → 내비 목적지 변경 → 가족 앱에 "아빠가 OO치킨으로 가요"
- 시동·도착 때는 가족 인사 영상, 졸음이 의심될 때는 **가족이 미리 녹음한 목소리** → 오가는 길 내내 **가족과 함께 타는 느낌**
- 앱 카테고리: ⬜ 확인 필요 (`공모전_가이드_정리.md`의 카테고리 목록에서 고른다. 후보: Mobility Services, 커뮤니케이션 계열)

## 2. 왜 필요한가

### 2-1. 숫자 (모두 근거 수집 전, `근거_수집목록.md` 참고)
- 40~50대는 출퇴근 운전 시간이 길고, 신차 주 구매층이다 (A1·C2)
- 운전 중 휴대폰으로 메시지를 확인·입력하는 행동이 사고 위험을 크게 높인다 (A3·B2)
- 고속도로 사망 사고에서 졸음·주시 태만 비중이 높다 (A4)
- 가족 대화 시간이 짧고, 그중 아빠와 자녀의 대화가 가장 적다 (A5)

### 2-2. 사람의 이야기
- **아빠(52세)**: 회사까지 편도 한 시간 운전. 운전 중 가족 카톡이 오면 신호 대기 때 몰래 보거나 집에 와서야 확인한다. 야근 뒤 밤길에 졸음이 온다.
- **딸(22세, 대학생)**: "아빠 어디야?"를 묻고 싶지만 운전 중일까 봐 전화를 미룬다.
- **아내(50세)**: 퇴근길에 "두부 좀 사 와"를 부탁하려다 이미 집 앞이라 늦는다.

### 2-3. 왜 차량 앱이어야 하나 (차량특화성)
- 휴대폰은 **지금 운전 중인지, 기어가 P인지, 졸음 신호가 있는지**를 모른다. 차량은 속도·기어·조향·깜빡이로 안다
- 메시지를 **차량 스피커로 읽고 말로 답하게** 하면 휴대폰을 집어 들 이유가 없어진다
- 가족이 보낸 장소를 **아빠의 "응" 한마디로 차량 내비 목적지로 바꿀 수 있는 건** 차량 앱뿐이다 (NaviHelper `requestRoute`)
- 퇴근 출발·도착을 **차가 알아서 알기 때문에** 아빠가 아무것도 안 해도 가족에게 "출발했어요", "도착했어요"가 간다
- 영상은 **기어 P일 때만**, 주행 중에는 화면 없이 소리만 → 주행 규제 원칙과 일치

## 3. 설계 원칙

1. **가족이 먼저 다가온다**: 대화를 시작하는 쪽은 가족이다. 아빠가 차에게 명령하는 구조가 아니라, 가족이 보낸 것을 아빠가 받는 구조
2. **아빠는 듣고 "응"만**: 아빠가 할 일은 듣고 예/아니요로 답하는 것뿐. 검색·입력·음성 명령을 요구하지 않는다
3. **주행 중엔 귀로만**: 화면을 보거나 만질 일을 만들지 않는다. 영상은 소리만 먼저, 화면은 정차(기어 P) 때
4. **묻고 나서 실행한다**: 경로 변경은 항상 운전자가 "응" 해야 실행. 가족 앱이 차를 직접 조작하지 않는다
5. **잔소리가 아니라 가족 목소리**: 졸음·장시간 운전 같은 순간에는 경고음 대신 가족이 미리 녹음한 말
6. **공유는 운전자가 주인**: 퇴근길 자동 공유는 운전자가 한 번 켜 둔 경우만. 도착하면 자동 종료. "감시"가 되지 않게

## 4. 시스템 구조

```
[가족 앱 (Android, Kotlin)]  ──메시지·음성·영상·장소──▶  [Firebase]
        ▲                                                │  Auth / Firestore / Storage
        │ 위치·도착 예정 시간·답장                         │  Cloud Functions: LLM 의도 파악, TTS 음성 파일 생성
        │                                                ▼
        └────────────────────────────────────────  [차량 앱 (Pleos Connect, Kotlin)]
                                                    포그라운드 서비스: 수신·낭독·질문·실행·습관 감지
                                                    정차 화면: 인사 영상, 메시지함, 설정
```

- **차량 쪽 수신**: Firestore 실시간 리스너가 기본. FCM은 에뮬레이터·실차의 Google Play 서비스 유무 확인 후 결정 ⬜
- **처리 무거운 일은 서버에서**: 의도 파악(LLM), TTS 음성 파일 생성, 음성·영상 보정 → 차량은 **재생과 SDK 호출만** (주행 중 CPU 5% 미만 기준)
- **TTS**: Pleos TTS SDK는 에뮬레이터에서 내부 오류(6장) → **서버에서 음성 파일로 만들어 내려보내는 방식이 기본**, Android 내장 `TextToSpeech`는 대안으로 확인 ⬜
- **음성 응답**: Android `SpeechRecognizer`로 "응/아니" 인식 ⬜ + 화면 큰 버튼 두 개(예/아니요) 병행

## 5. 기능 목록

**우선순위** P0: PT 필수 / P1: 가능하면 구현 / P2: 기획서 확장 계획
**상태** ✅ 실측 동작 / ⬜ 확인 필요 / 📱 가족 앱·서버 구현 / 🎭 시연은 대체 방식

**핵심 흐름** (기능 A~C는 이 순서로 이어진다)
```
아빠 퇴근 출발 → 위치 공유 시작 → 가족에게 "아빠 출발했어요"
→ 가족이 앱에서 아빠 위치를 보고 영상·음성 메시지에 장소를 붙여 보냄
→ 차: "지은이가 장소를 보냈어요. 음성 메시지가 있어요" → 메시지 소리 재생 → "목적지를 OO치킨으로 바꿀까요?"
→ 아빠 "응" → 내비 목적지 변경 → 가족 앱에 "아빠가 OO치킨으로 가요" → 도착하면 공유 종료, "아빠 도착했어요"
```

### 5-1. B7 메시지 속 장소 제안 (서버 LLM, 보조 기능)
- 기본 흐름은 가족이 장소를 직접 붙여 보내는 것이다. LLM은 장소를 안 붙인 메시지를 도와주는 보조 기능
- 가족 앱에서 메시지가 올라오면 Cloud Function이 LLM에 보내 **의도와 장소**를 뽑아 메시지에 붙여 차량으로 내려보낸다
- 결과 형식 (예):
  ```json
  { "intents": ["ADD_WAYPOINT"], "place_query": "치킨", "place": {"name": "OO치킨", "lat": 0, "lng": 0},
    "speak": "지은이가 '아빠 올 때 치킨 사 와'라고 보냈어요.", "ask": "OO치킨을 경유지로 넣을까요?" }
  ```
- 의도 종류: `LOCATION_REQUEST`(어디야), `ETA_REQUEST`(언제 와), `ADD_WAYPOINT`(사 와, 들러), `SET_DESTINATION`(여기로 와), `NONE`
- **장소는 가족이 고른다**: 메시지에 장소가 나오면 가족 앱이 검색 결과를 먼저 보여 주고 가족이 하나를 붙인다. LLM이 임의로 고른 장소로 경로를 바꾸지 않는다
- 질문은 한 번에 하나. 의도가 여러 개면 위치 공유 → 경로 변경 순으로 하나씩
- LLM 실패·지연 시 메시지만 읽고 질문은 생략 (기능이 멈추지 않게)
- 개인정보: 메시지 원문이 외부 LLM으로 전송됨 → 동의 항목, 학습 미사용 옵션 확인

### 5-2. E1~E4 운전 습관 판단 (숫자는 모두 예시)
**입력** (에뮬레이터 실측 ✅): 속도(`PERF_VEHICLE_SPEED`), 조향각(`SteeringWheel`), 깜빡이(`TurnSignal`), 기어(`GEAR_SELECTION`), 시각, 경로 목적지(NaviHelper)
운전자 카메라·주의 경고(`DRIVER_ATTENTION`)는 실차 특수 권한이라 쓰지 않는다. 차로 정보 API도 없다.

| 상황 | 판단 (예시) | 단계·멘트 |
|---|---|---|
| 졸음 의심 | 고속(예: 시속 60km 이상)에서 ① 조향 미세 보정이 평소보다 오래 없다가 큰 각도로 급히 꺾음(조향 반전), ② 깜빡이 없는 조향 흔들림 반복, ③ 속도 유지가 평소보다 불안정. 심야(0~6시)·연속 운전 시간이 길면 가중 | 1단계: 짧은 신호 + "아빠 괜찮아?" → 2단계: 조명 깜빡임 + **"아빠 일어나!!"** → 이후: "아빠 졸음쉼터에서 좀 쉬었다 가" |
| 장시간 연속 운전 | 정차(기어 P) 없이 예: 2시간 | "아빠 좀 쉬었다 가" (주행 중 한 번, 이후 30분 간격 최대 2회) |
| 평소와 다른 시간 | 평소 퇴근 출발 시각보다 예: 1시간 이상 늦음 | 출발 전(기어 P) "아빠 오늘 늦었네, 조심히 와" |
| 평소와 다른 경로 | 평소 목적지(집)가 아닌 곳으로 늦은 밤 출발 | 출발 전 "아빠 오늘 고생 많았어, 천천히 와" |

- **평소 기준은 그 운전자의 주행으로 학습**한다 (예: 첫 10회 주행의 조향 보정 빈도·속도 변동·출발 시각). 사람마다 운전 습관이 달라서 고정 기준보다 오경보가 적다
- **잔소리가 되지 않게**: 같은 종류는 예: 10분 안에 다시 울리지 않음, 하루 최대 횟수 제한, 운전자가 "괜찮아"라고 답하면 그 주행에서 1단계 생략
- **가족에게 자동으로 알리지 않는다**: 졸음·늦은 퇴근 같은 판단 결과는 차 안에서만 쓴다 (감시 방지)
- 의학적·인증된 졸음 감지가 아니라 **"졸음 의심 신호"**로 표현. 차량 기본 안전 기능을 대체하지 않음
- 시연: Virtual Console로 조향 값을 일정 시간 고정했다가 큰 값으로 바꿔 재현 🎭

## 8. 정책·위험

- **주행 중 알림**: Pleos 심사 기준 "운전과 관련 없는 알림 금지"와 충돌 소지 → **화면 없이 음성만, 짧게, 운전자가 켠 기능**이며 **휴대폰을 집어 들지 않게 하는 안전 대안**으로 설명. 주최 측 문의 필수
- **단일 경로 정책**: 우리는 길 안내를 하지 않고 내장 내비에 목적지·경유지를 **요청만** 한다 (`requestRoute`)
- **위치정보**: 실시간 위치를 서버에 저장·전달 → 위치기반서비스사업 신고 요건 검토. 공유는 수락 시만, 도착 시 자동 종료, 기록 보관 기간 최소화
- **외부 LLM 전송**: 가족 메시지 원문이 LLM API로 전송됨 → 동의, 학습 미사용, 실패 시에도 기능 동작
- **운전 데이터**: 졸음·습관 판단은 차 안에서만, 가족에게 자동 공유 안 함. **마케팅 사용 금지** 규정 준수 → 보험 연계는 본인 동의 기반으로만
- **감시 인식**: "위치 추적"이 아니라 "운전자가 보내 주는 위치"로 설계·표현
- **에뮬레이터와 실차 권한 차이**: `PRIVATE_CAR_SAFETY`·`DRIVER_ATTENTION`은 실차 특수 권한 → 사용 안 함
- **비공식 API 금지**: 에뮬레이터의 문서에 없는 ADAS 서비스는 쓰지 않음
- **성능 기준**: 내비 외 앱 주행 중 CPU 5% 미만, RAM 400MB 이하 → 이벤트 기반 + 무거운 처리는 서버

- **사용자가 둘 이상**: 운전자(차량 앱) + 가족(휴대폰 앱) → 가족이 매일 들어올 이유가 있음 (메시지, 영상, 위치 확인)
- **Retention**: 출퇴근마다 자동 동작(따로 켤 필요 없음), **퇴근할 때마다 가족에게 "아빠 출발했어요" 알림 → 가족이 매일 앱을 연다**, 시동 때마다 가족 영상, 가족이 새 영상·멘트를 계속 올림
- **MAU 수식**: `Pleos 탑재 차량 수 × 40~50대 주 운전자 비율 × 설치율 × 월 1회 이상 사용률` + 연결된 가족 수
- **수익 모델**: 기본 무료 / 가족 프리미엄 구독(가족 수·영상 저장 용량·AI 기능) / 차량 커넥티드 서비스 패키지 / 보험 안전운전 연계(휴식 권유 응답 등, 본인 동의 시)
- **확장**: 5장 X 항목
