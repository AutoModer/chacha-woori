## A. 길목 감지

### A1. 다음 길목 감지 — P0
- **하는 일**: 경로 안내 중 다음 회전·출구 정보를 계속 받는다.
- **입력**: NaviHelper `onTBTInfo` → `TBTInfo(type, distance, description)` ✅
- **동작 조건**: `RouteStateInfo.isRouting == true` (경로 안내 중일 때만)
- **예외**: 목적지가 없으면 동작하지 않음 (적용 범위로 명시)

### A2. 길목 중요도 분류 — P0
- **하는 일**: 모든 회전을 알리지 않고, **놓치면 위험하거나 돌아가기 힘든 길목**만 고른다.

| 등급 | TurnType 예 | 알림 |
|---|---|---|
| 높음 | `TURN_EXIT_IC_L/R/C`(고속도로 출구), `TURN_DEVIDE_MERGE`(분기·합류), `TURN_ENTER_IC_*`(고속도로 진입), `TURN_KEEP_L/R`(분기 방향 유지) | 준비·재촉·재안내 모두 |
| 중간 | `TURN_ENTER_UNDER_*`, `TURN_ENTER_OVER_*`, `TURN_AVOID_*`(지하·고가차도), `TURN_ENTER_ROUNDABOUT_*` | 준비 신호만 |
| 낮음 | `TURN_LEFT/RIGHT`(일반 교차로), `TURN_STRAIGHT`, `TURN_TOLL`, `TURN_TUNNEL` | 기본은 알리지 않음 (설정으로 켤 수 있음) |

- **왼쪽 출구 가중치**: `*_L` 출구는 드물고 예상하기 어려워 한 단계 일찍 알림

### A3. 남은 시간 계산 — P0
- **하는 일**: 남은 시간 = 남은 거리 ÷ 현재 속도
- **입력**: `TBTInfo.distance` ✅, 속도 AAOS Car API ✅
- **예외**: 속도가 아주 낮으면(정체, 시속 10km 미만) 시간 대신 거리 기준으로 전환 (예: 300m)

## B. 운전자 반응 판단

### B1. 출구 쪽 깜빡이 감지 — P0
- **입력**: Vehicle `TurnSignal.registerTurnSignalState` ✅
- **판단**: 길목 방향과 같은 쪽 깜빡이만 인정. **켰다가 바로 꺼도 인정** (알아차렸다는 증거)
- **결과**: 반응 있음 → 해당 길목 알림 종료

### B2. 출구 쪽 조향 변화 감지 — P0
- **입력**: Vehicle `SteeringWheel.registerSteeringWheelAngle` ✅
- **판단**: 출구 방향으로 기준각 이상(예: 5도)을 일정 시간 이상(예: 1.5초) 유지
- **커브 오인 방지**: 길목까지 남은 거리가 먼 구간의 조향 변화는 무시하거나, 기준을 높임 (실험으로 조정)

### B3. 크루즈 해제 감지 — P1
- **입력**: Vehicle `DrivingMode.registerCruiseControlState` ✅
- **판단**: `SUSPENDED`, `USER_OVERRIDE`는 반응으로 인정. `FORCED_DEACTIVATION_WARNING`은 제외
- **추가 활용**: `ACTIVATED`가 오래 지속되면 C5 시점 보정에 사용

### B4. 상황 종료 감지 — P0
- **판단**: TBT 다음 안내가 바뀜(길목 통과), `onReRouteEnded`(재탐색), `onRouteCancelled`, `onDestinationArrived`
- **결과**: 진행 중인 알림 모두 정리

## C. 단계별 알림 (판단 엔진)

| 단계 | 조건 (예시) | 출력 |
|---|---|---|
| C1 대기 | 남은 시간 > 90초 | 없음 |
| C2 준비 | 남은 시간 ≈ 90초 | 출구 방향 신호 한 번 |
| C3 재촉 | 남은 시간 ≈ 40초, 반응 없음 | 남은 시간이 줄수록 빨라지는 반복 신호 |
| C4 재안내 | 남은 시간 < 10초, 반응 없음 | 재촉 중단, "괜찮아요, 다음 출구로 안내할게요" |

### C2. 준비 신호 — P0
- 이미 맞는 차선에 있어도 울림 (차로를 알 수 없으므로). "곧 내린다"는 예고라 틀린 안내가 아님
- 길목마다 **한 번만**

### C3. 재촉 신호 — P0
- 간격이 점점 짧아짐 (예: 5초 → 3초 → 1.5초)
- 반응(B1~B3)이 오면 즉시 멈춤

### C4. "괜찮아요" 재안내 — P0
- 재촉을 멈추고 차분한 톤으로 안내
- 다음 길목은 준비 시점을 한 단계 앞당김
- 놓친 길목은 F3 길목 기억에 기록
- **PT 핵심 장면**: 기존 내비의 "경로를 이탈했습니다"와 나란히 비교

### C5. 시점 보정 — P1
- 준비·재촉 시점을 앞당기는 조건
  - 크루즈 `ACTIVATED` 장시간 지속
  - 교통 혼잡 (NaviHelper `TrafficCongestionInfo`) ✅
  - 왼쪽 출구 (A2)
  - 이전에 놓친 길목 (F3)
  - 운전자 주의 경고 `DRIVER_ATTENTION` 🔒 (읽을 수 있을 때만)
- 사용자 설정(F2)의 "더 일찍" 단계 반영

### C6. 알림 중복 방지 — P0
- 한 번 해제된 길목은 다시 울리지 않음
- 길목이 연달아 있으면(예: 출구 직후 분기) 앞 길목 알림이 끝난 뒤 다음 길목 준비 신호
- 위험 경고(차량 자체 경고음)가 울리는 중에는 앱 신호를 미룸 (가능한 범위에서)

## D. 출력

### D1. 방향 신호음 — P0 ✅
- 낮고 또렷한 짧은 소리 (노인성 난청 고려, 고음 피함)
- 준비와 재촉을 다른 소리로 구분
- 좌우 스피커로 방향 표시 (가능 여부 실험 필요)
- 음악을 끄지 않고 짧게 얹음 (오디오 포커스 정책 준수)

### D2. 실내 조명 신호 — P1 ⏳
- 출구 쪽 좌석 구역(`SeatArea`) 앰비언트 조명 색·밝기 변경
- 준비: 은은하게 한 번 / 재촉: 밝기를 반복해서 바꿈 (깜빡임 API 없음)
- 알림이 끝나면 **원래 조명 상태로 복구**
- 고령자에게 특히 중요 (소리를 못 들을 때의 보완)

### D3. 짧은 음성 안내 — P1 ⏳
- 한 번에 한 가지 행동만: "오른쪽으로 가실게요", "괜찮아요, 다음 출구로 갈게요"
- TTS가 안 되면 미리 녹음한 음성 파일로 대체

### D4. 출력 자동 선택 — P0
- H1 결과에 따라 쓸 수 있는 출력만 조합 (조명이 없으면 신호음만)
- 사용자 설정(F2)에서 출력별 켜고 끄기

## E. 정차 화면 (주차·정차 중에만)

### E1. 출발 전 미리 보기 — P1
- 경로가 정해지면 "오늘 길에 알려 드릴 곳 두 곳"
- 지난번에 놓친 길목이 있으면 "여기는 조금 더 일찍 알려 드릴게요"

### E2. 오늘의 운전 — P0
- 도착(`onDestinationArrived`) 후 표시
- 큰 글씨, 한 화면, 칭찬 중심: "오늘 길목 다섯 곳을 잘 지나셨어요"
- 놓친 곳은 탓하지 않고 "다음엔 더 일찍 알려 드릴게요"
- 점수, 등급, 순위 없음

### E3. 길목 기록 — P2
- 지금까지 지나온 길목, 자주 다니는 길, 일찍 알림을 받는 길목 목록

## F. 개인화

### F1. 첫 설정(온보딩) — P0
- 질문 세 개 이하, 큰 버튼
  1. 알림 시점: 보통 / 조금 일찍 / 많이 일찍
  2. 알림 방식: 소리 / 소리+빛 / 소리+빛+말
  3. 가족에게 도착 알림: 켬 / 끔
- 처음 쓰는 사람을 위한 신호 미리 듣기

### F2. 알림 세기·시점 설정 — P1
- 신호음 크기, 시점 단계, 길목 등급별 켜고 끄기 (일반 교차로 회전도 알릴지)

### F3. 길목 기억(학습) — P1
- 반응이 늦었거나 놓친 길목을 위치·종류로 저장
- 다음에 같은 길목에서 시점 보정(C5)
- 같은 길목을 여러 번 잘 지나가면 보정을 서서히 줄임 (익숙해지면 덜 알림)
- **차량 안에만 저장** (H4)

## G. 가족 (운전자가 켜야만 동작) 📱

### G1. 출발·도착 알림 — P1
- "출발하셨어요", "병원에 도착하셨어요"
- 1차: 화면 시안 또는 목업 / 2차: 가능하면 간단한 서버 연동

### G2. 주행 요약 공유 — P2
- 놓칠 뻔한 곳 수 정도만, 위치 기록은 기본 비공유

### G3. 목적지 보내기 — P2
- 자녀 휴대폰 → 차량으로 목적지 전송 → 차에서 한 번 눌러 출발 (NaviHelper `requestRoute` ✅)

## H. 시스템

### H1. 차량 기능 지원 확인 — P0
- 시작할 때 `checkXXXCapabilities`로 깜빡이, 조향, 크루즈, 조명 지원 여부 확인
- 안 되는 기능은 조용히 빼고 동작 (오류 화면 없음)

### H2. 백그라운드 동작 — P0
- 경로 안내가 시작되면 자동으로 동작, 따로 앱을 켜지 않아도 됨
- 리스너 등록·해제 관리 (`initialize` / `release`)

### H3. 주행 규제 대응 — P0
- `CarUxRestrictions`로 주행 중 화면 기능 비활성화
- 주행 중에는 화면 없이 소리·빛만
- 앱 카테고리 가정: Mobility Services (확인 필요)

### H4. 개인정보 보호 — P0
- 길목 기억과 주행 요약은 **차량 안에 저장**
- 가족 공유는 본인이 켤 때만, 보낼 내용을 화면에 미리 보여 줌
- 언제든 기록 삭제 가능

### H5. 시연 모드 — P0
- 내비 시뮬레이션 주행(`SIMULATION_GUIDING`) + Virtual Console(속도, 조향, 깜빡이)로 장면 1·2를 재현
- 실제 경로가 안 나오면 미리 만든 TBT 시나리오를 재생하는 테스트 모드
- PT에서 "기존 내비 vs 길목 도우미" 나란히 비교

## PT 시연 최소 범위 (P0만으로 보여 줄 장면)

1. 온보딩(F1)에서 "조금 일찍" 선택
2. 시뮬레이션 주행으로 오른쪽 고속도로 출구 접근 (A1~A3)
3. 90초 전 준비 신호음 (C2, D1)
4. 깜빡이를 켜면 즉시 멈춤 (B1)
5. 다음 출구에서는 반응 없이 진행 → 재촉 → "괜찮아요" 재안내 (C3, C4)
6. 도착 후 "오늘의 운전" 화면 (E2)

조명(D2)이 에뮬레이터에서 동작하면 3번과 5번에 조명 장면을 추가

## API로 구현 가능한지 검토 (2026-11-09)

### 제공 API만으로 가능 ✅
A1, A2, A3, B1, B3, B4, C1, C2, C3, C4, D4, E2, F1, F2, H1, H3, H4
- A3 속도는 Pleos SDK가 아니라 AAOS 표준 Car API(`PERF_VEHICLE_SPEED`)
- C·D4·F는 앱 자체 로직과 저장소(SDK 불필요)

### 가능하지만 한계가 있음 ⚠️
| ID | 한계 | 대응 |
|---|---|---|
| B2 조향 변화 | 도로 곡률 정보가 없어 커브와 차선 변경을 완벽히 구분 못 함 | 각도 + 유지 시간 + 남은 거리로 추정, 실험으로 조정 |
| C5 시점 보정 | 교통 혼잡·크루즈는 가능, `DRIVER_ATTENTION`은 특수 권한 추정 | 주의 경고는 확장으로 |
| D1 방향 신호음 | 신호음 재생은 가능. 좌우 스피커 분리는 차량 오디오 라우팅에 달려 미확인. 내비 안내 용도 오디오는 음악을 잠깐 줄일 수 있음(끄지는 않음) | 좌우 분리는 실험, 안 되면 소리 종류로 방향 구분 |
